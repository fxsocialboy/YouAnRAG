# 国务院办公厅印发关于地震灾区恢复⽣产指导意⻅的通知

国办发〔2008〕52号

各省、⾃治区、直辖市⼈⺠政府，国务院各部委、各直属机构：

《关于地震灾区恢复⽣产的指导意⻅》已经国务院同意，现印发给你们，请认真贯彻执⾏。

做好地震灾区恢复⽣产⼯作，对于搞好抗震救灾，促进灾区经济社会发展，具有⼗分重要的意义。当前，恢复⽣产⼯作已经取得阶段性进展，但任务仍⼗分艰巨。各地区、各部⻔要充分认识做好灾区恢复⽣产⼯作的重要性，增强紧迫感和责任感，按照党中央、国务院的统⼀部署，把恢复⽣产和灾后重建摆在更加突出的位置，加强协调配合，认真组织实施，确保灾区⼯业、农业、服务业等早⽇恢复。

国务院办公厅⼆〇〇⼋年六⽉⼗

六⽇

# 关于地震灾区恢复⽣产的指导意⻅

为切实做好地震灾区恢复⽣产⼯作，尽快恢复灾区⽣产、⽣活基本条件，促进灾区经济社会发展，夺取抗震救灾的全⾯胜利，特制定本意⻅。

# ⼀、指导思想和主要原则

# （⼀）指导思想。

贯彻落实科学发展观，按照党中央、国务院的统⼀部署，充分发挥灾区各级⼈⺠政府、企业和⼴⼤⼲部群众的主体作⽤，坚持⾃⼒更⽣、⽣产⾃救；加⼤政府⽀持⼒度，⿎励社会⼴泛援助，调动各⽅⾯积极性，形成合⼒；统筹⼈⼒物⼒财⼒，加强与灾后恢复重建规划的衔接，确保灾区⼯业、农业、服务业等早⽇恢复。

# （⼆）主要原则。

1、统筹安排，确保重点。坚持恢复⽣产与抗震救灾急需相结合。科学评估受灾损毁情况，科学制定恢复⽣产⽅案，以修复重要基础设施、抓好农业抢收抢种、搞活商贸流通、保障救灾物资和群众⽣活、保证国家重点⼯程为重点，分类指导，先急后缓，分步实施。

2、主动⾃救，多⽅⽀援。国家积极组织各⽅⾯⼒量，实施对⼝⽀援，加⼤政策⽀持和社会帮扶⼒度。同时，充分依靠灾区各级⼈⺠政府，组织受灾企业和⼲部群众开展⽣产⾃救，⾃⼒更⽣、艰苦奋⽃，减轻灾害损失。

3、调整结构，优化布局。灾区受损严重企业恢复⽣产，要与调整区域⽣产⼒布局和产业结构相结合，贯彻国家产业政策，按照市场需求，结合当地资源、环境条件，发展优势产业。要与推进节能减排、淘汰落后⽣产能⼒和促进企业技术进步相结合，推动产业升级，促进可持续发展。

4、注重安全，防范事故。加强地震监测，防范次⽣灾害。加强隐患排查治理，严格安全审查验收，确保在安全前提下恢复⽣

5、⼴开渠道，扩⼤就业。实施多种形式的就业援助，开发公益服务等就业岗位，加强岗位技能培训，开展以⼯代赈，增加就业机会，⿎励多渠道多形式就业。

# ⼆、主要任务

# （⼀）⼯业。

1、分类分批组织恢复⽣产。组织技术⼒量，指导组织重点企业对⼚房、设备加快检测鉴定，分批抓紧复产。基本具备恢复⽣产条件的，要尽快恢复⽣产；需要重建或异地重建的，纳⼊灾后重建规划。

2、抓紧恢复⽣产要素的⽣产供应。加⼤煤炭、成品油、天然⽓、矿⽯等物资的调运⼒度，加快电⼒系统抢修进度，优先恢复供电、供⽓、供⽔、煤矿等企业⽣产，为全⾯恢复⼯业⽣产创造条件。

3、努⼒确保⽣产救灾、重建物资企业的恢复。协调解决企业流动资⾦、原材料供应、产品运输等突出问题，加紧组织帐篷、活动板房、⻝品、消毒防疫⽤品、⽔泥、建材、化肥、农药、农膜、农⽤机械、饲料等企业尽快恢复⽣产。

4、重点⽀持⼤型⻣⼲企业恢复⽣产。对短期内可以恢复⽣产的重点⻣⼲企业，要组织⼒量重点帮扶，指导制定复产⽅案，尽快恢复⽣产。要统筹考虑中央企业恢复⽣产⼯作，积极协调解决⽣产要素供应和供电、供⽔、供⽓等外部保障条件，以及职⼯安置和住房重建问题。

5、加强对中⼩企业恢复⽣产的政策指导。优先恢复资信好、技术含量⾼以及劳动密集、与⼤企业协作配套的中⼩企业⽣产。对于受损较重、严重浪费资源、污染环境和不具备安全⽣产条件的企业不再恢复，合理关停并转。

6、积极组织实施对⼝⽀援。落实国务院确定的对⼝⽀援⽅案，有效组织同⾏业、同类企业，尤其是⼤型⻣⼲企业，对受灾严重的企业进⾏对⼝帮扶。以市场为导向，组织引导东部地区企业通过联合、兼并、重组等多种⽅式参与恢复和重建。

7、加快⼯业园区恢复。对具有资源优势和环境承载能⼒的地区，加快修复⼯业园区的基础和服务设施，尽快恢复园区功能，为企业恢复⽣产和产业集聚创造条件。

# （⼆）农业、林业。

1、抓好抢收抢种。积极组织和调剂农机及农⽤柴油、种⼦、化肥、农药、农膜等农业⽣产资料，继续组织好夏收归仓，推进夏播夏种，抓紧开展改种、补种，切实做到应收尽收、应种尽种。

2、抢修农业⽣产和服务设施。抓紧对农⽥基础设施、良种繁育设施、温室⼤棚、农机具等进⾏抢修，及早恢复农业技术推⼴、农产品市场信息等服务。

3、加快恢复养殖业⽣产。组织好仔畜雏禽的调运⼯作，优先保证灾区所需疫苗、饲料等物资供应，充分利⽤⻘绿饲料资源；抓紧修复受损的畜禽圈舍、⻥池⻥塘，加快补栏、补苗，尽快恢复畜禽及淡⽔养殖业⽣产。

4、尽快恢复林业⽣产能⼒。组织抢修受损林⽊、种苗⽣产基地基础设施，恢复林⽊种⼦、苗⽊⽣产；尽快恢复受损的森林防⽕基础设施；恢复和加固⼈⼯饲养⼤熊猫等野⽣动物圈舍。

5、加强对灾区农林⽣产的指导和服务。组织技术⼈员指导、帮助开展⽥间和林间管理，有针对性地开展技术培训，提⾼⽣产⾃救能⼒；强化病⾍害监测、预警和检疫⼯作，推进病⾍害统防统治和专业化防治，做好有害⽣物防控和应急处置⼯作。

6、强化动物疫病防控。继续做好死亡畜禽、⻥类和野⽣动物的⽆害化处理和消毒防疫，强化⼈畜共患疾病的免疫⼯作，加⼤⿏害防控⼒度，防⽌发⽣重⼤动物疫情和⼈畜共患疾病流⾏。

# （三）商贸流通。

1、尽快恢复灾区商业⽹点。在受灾群众集中居住地安排流动售货⻋、帐篷商店和板房便⺠商店等商业⽹点，区分轻重缓急，逐步恢复原有固定商业零售⽹点；安排好符合少数⺠族⻛俗习惯商业⽹点的恢复和商品供应。

2、积极为灾区群众提供急需的基本⽣活服务。⿎励和引导企业在重灾区建设⼀批⼤众⻝堂和主⻝加⼯配送中⼼；在受灾群众集中安置点建设公共洗浴场所和洗⾐⽹点。

3、切实保障灾区重要商品供应。组织调运、配送⻝品和⽇⽤消费品等急需商品；建⽴农产品绿⾊通道，搞活农产品流通；为灾区群众提供安全、便利、实惠的⽣活必需品和⽣产资料。

4、维护灾区正常市场秩序。密切监测灾区重要⽣活⽤品和⽣产资料的市场供求变化及价格⾛势，严厉打击囤积居奇、哄抬物价和商业欺诈、假冒伪劣、以次充好等⾏为。

# （四）基础设施。

1、尽快抢通灾区公路、铁路。集中⼒量抢通符合重建规划要求的国道、省道和通往重要⼯矿企业、重点林区的专⽤道路，加强

已抢通公路、铁路的监测和维修，道路抢通⼯作要向乡村延伸。

2、尽快恢复电⽹正常运⾏。优先保证⻣⼲⽹架和受损严重地区电⽹的恢复。

3、尽快恢复灾区通信。围绕“保县、保乡、保救灾”的⼯作重点，及时抢修受损通信局（所）、通信设备、传输线路等设施，尽快使灾区公众通信能⼒基本恢复正常。

4、尽快恢复受灾群众集中地区的供⽔、排⽔。及时抢修恢复受灾较轻的城乡供排⽔系统和污⽔处理设施，在受灾群众集中安置点设置供⽔系统，加强⽔质监测，保障供⽔和⽔质安全。

5、尽快恢复其他基础设施。加快修复病险⽔库、⼴播电视、学校、医院等基础设施。

# （五）⾦融服务。

1、银⾏业。抓紧修复受损机构⽹点，尽快恢复⾦融服务；核实震前存贷款的⻛险状况，做好⻛险评估和不良资产处置⼯作，维护债权⼈、债务⼈的合法权益，防⽌恶意逃废银⾏债务；抓紧制定和落实灾区⾦融机构⽹点、基础设施恢复重建规划；加强银⾏业⾦融服务应急管理，在地⽅政府的⽀持下，防范和打击⾦融犯罪，保障⾦融安全，维护⾦融秩序和⾦融稳定。

2、证券业。加快对营业⽹点建筑物进⾏安全评估和排险加固；尽快恢复证券期货经营机构场地、设备等交易和服务设施；维持⽹上交易、电话委托等交易途径通畅；妥善处理震灾死难、失踪⼈员家属对死难者和失踪⼈员证券基⾦期货资产的权利主张。

3、保险业。抓紧修复保险业务系统，尽快恢复保险业务正常经营；认真做好灾后理赔服务⼯作，简化理赔程序，尽快到位理赔资⾦；抓紧做好保险营业⽹点的重建规划。

# （六）旅游业。

1、分类制定旅游业恢复计划。抓紧恢复旅游接待能⼒，确定陆续恢复旅游接待的地区、线路、时间和措施，并适时公布。根据旅游基础设施、接待设施的损毁程度和接待能⼒，在具备条件时依次分批启动旅游接待。适时开展旅游宣传促销，逐步恢复旅游市场信⼼。

2、强化旅游安全。恢复旅游接待必须通过安全检查评估，加强旅游设施设备的检修维护，排查整改安全隐患，加强应急响应和紧急救援准备。

3、确保旅游服务质量。加强旅游市场秩序监管和服务质量投诉受理，恢复旅游接待的规模要严格控制在接待能⼒、环境承载⼒和供应保障能⼒范围之内。

# 三、组织实施

（⼀）加强组织领导。地⽅各级⼈⺠政府和国务院有关部⻔要充分认识当前的严峻形势，树⽴全局意识，增强使命感和责任感，在继续做好受灾群众安置⼯作的同时，把恢复⽣产和灾后重建摆在更加突出的位置，建⽴健全强有⼒的恢复⽣产领导体制，统⼀指挥，明确任务，落实责任。各地要结合实际，根据本意⻅制定和完善恢复⽣产的具体⽅案。

（⼆）注重协调配合。地⽅各级⼈⺠政府负责恢复⽣产⼯作的组织实施，国务院有关部⻔要加强协调、指导，及时解决出现的各种问题，切实做好服务。地⽅各级⼈⺠政府和有关部⻔要认真负责、紧密配合，充分调动各⽅⾯的积极性，共同做好恢复⽣产⼯

（三）制定扶持政策。鉴于灾区各类企业和个体⼯商户在地震中财产损失巨⼤，恢复⽣产任务繁重，需要在财政⽀持、税收减免、贷款贴息、信贷⽀持、⾦融机构不良资产处置、就业援助、产业政策以及对困难国有企业注⼊国有资本⾦等⽅⾯给予政策扶持，请财政、税务、⾦融、社保、国资监管等有关部⻔和单位，根据国务院抗震救灾总指挥部第⼗六次会议精神，抓紧研究相关政策报国务院审批。

（四）强化监督检查。加强财政资⾦使⽤的监督管理，充分发挥资⾦使⽤效率。审计、监察部⻔要适时开展恢复⽣产专项检查，及时公布检查结果，及时处理违法违纪问题。进⼀步强化恢复⽣产过程中的安全监管监察。充分发挥新闻媒体的舆论监督作⽤，为恢复⽣产创造良好的社会环境。
