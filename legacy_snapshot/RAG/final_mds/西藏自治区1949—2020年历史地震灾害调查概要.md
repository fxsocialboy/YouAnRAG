# Overview of historical earthquake disasters in Xizang Autonomous Region from 1949 to 2020

Bai Weiguo1), Sun Dongxia2, 3), Wu Zhonghai2, 3), Zhang Yaoling2, 3), Han Shuai2, 3), Gongqiu Zhuoma1)

1) Earthquake Agency of Xizang Autonomous Region, Xizang Lhasa 850002, China   
2) Institute of Geomechanics, Chinese Academy of Geological Sciences, Beijing 100081, China   
3) Research Center of Neotectonism and Crustal Stability, China Geological Survey, Beijing 100081, China

Abstract    Earthquake is one of the natural disasters that pose a serious threat to the safety of human life and social development.  Earthquake  disasters  are  listed  as  an  important  disaster  type  in  the  first  national  comprehensive  risk assessment of natural disasters. Clarifying historical earthquake disaster data and understanding the development trend are of  great  significance  for  earthquake  prevention  and  scientific  plans  to  avoid  the  disaster  threats.  According  to  the earthquake disaster risk assessment implementation plan in Xizang Autonomous Region, a comprehensive collection of materials  was  conducted,  including  the  latest  earthquake  catalog  officially  published  by  the  earthquake  department, officially published compilations of earthquake damage reports, and earthquake report data summarized by the Earthquake Agency of Xizang Autonomous Region. This included 45 items such as earthquake disaster information tables, data cards, earthquake  disaster  survey  materials,  damage  assessment  reports,  summaries  of  earthquake  emergency  response  and disposal work. A thorough investigation, organization, and compilation of annual historical earthquake disaster statistics for each county-level administrative region from 1978 to 2020 were carried out, establishing a long-term spatial-temporal dataset of major historical earthquake disasters since 1949, which contains complete, detailed, and standardized data on intensity, scope, and disaster conditions. There were over 600 earthquakes with a magnitude of $M _ { \mathrm { S } } 5 . 0$ or above during the study period, causing 43 earthquake disasters, with a disaster rate of approximately $7 . 2 \%$ . Between 1949 and 2020, there were  5 major  earthquakes  that  caused  significant  casualties  and  economic  losses.  The  spatial  distribution  of  destructive earthquakes  is  primarily  controlled  by  tectonic  systems.  However,  based  on  the  actual  conditions  in  the  Xizang Autonomous Region, it is significantly influenced by the population distribution and the national economic situation of the areas where the earthquakes occur.

Keywords    Xizang Autonomous Region; historical earthquake disasters; earthquake prevention

# 0    引言

西藏自治区历史灾害调查与评估是西藏自治区第一次全国自然灾害综合风险普查的重要工作组成部分。该项工作旨在通过全面调查、整理、汇总 1978年以来自治区各县级行政区年度自然灾害灾情统计数据，建立 1949年以来全区重大自然灾害事件强度、范围、灾情等要素完整、内容翔实、数据规范的长时间序列重大历史自然灾害时空数据集[1]。

青藏高原东缘强震频度高且强度大，是我国地震灾害问题最为突出的地区之一。城市活断层探测、重大工程与城镇区的活断层鉴定等工作提升了青藏高原东缘及邻区强震构造的调查研究程度[2]。地处青藏高原内部的西藏自治区，受到印度欧亚板块碰撞的影响，地震灾害更为频发，开展地震地质调查是防震减灾、保障地质安全的重要举措，历史地震灾害调查更是为自治区地震灾害未来趋势发展研究、政府部门制定防震减灾计划、规划和有关科技人员研究震害提供科学依据。

# 1    西藏自治区地震活动基本特征

目前地震监测主要通过固定地震台网地震仪，对地震活动产生的地震波进行记录，从而确定地震活动的时间、地点和强度等信息，由这些信息组成的地震目录是研究区域地震活动的主要资料。西藏自治区采用国家地震台、区域地震台和利用邻省地震台站信号组建成了覆盖全区及邻近地区的具有 56个子台的地震台网，目前的测震台站密度使西藏自治区的理论地震监测能力达到了 $M _ { \mathrm { L } } 1 . 1 { \sim } 2 . 7 ^ { [ 3 ] }$ 。地震震级是量化地震释放能量大小，定量评价地震活动强度的主要度量。常用的地震震级包括里氏震级、矩震级、面波震级等。里氏震级是根据地震仪记录到的最大地震波振幅计算的震级，通常用 $M _ { \mathrm { L } }$ 表示。矩震级是根据地震释放能量计算的震级，通常用 $M _ { \mathrm { W } }$ 表示。面波震级是根据地震产生的面波振幅计算的震级，通常用 $M _ { \mathrm { S } }$ 表示。本文采用面波震级衡量地震活动强度。

西藏自治区曾被划为地中海—喜马拉雅或南亚地震带中段，地震活动频繁、强烈且强度大、复发周期短，活动构造带是控制该地区地震、地热活动的最重要构造[4]。1900 年以来的青藏高原 6 级以上强震分布特点显示高原陆陆碰撞-挤出构造体系对区域强震活动起到显著控制作用[5]。根据中国地震台网中心国家地震科学数据中心（http://data.earthquake.cn）的地震目录，1949—2020 年，西藏自治区 $M _ { \mathrm { S } } 4 . 7$ 以上地震约 1400 次（图 1），绝大多数属浅源地震，其中 $42 \%$ 的地震震源深度小于 $1 0 \mathrm { k m }$ ， $1 8 . 7 \%$ 的地震震源深度集中在 $1 1 { \sim } 2 0 \mathrm { k m }$ ， $3 9 . 3 \%$ 的地震震源深度大于 $2 0 \mathrm { k m }$ 。

西藏自治区现今总体处于近东西向伸展与挤出变形环境，历史强震震级在 $M _ { \mathrm { S } } 6 . 0 { \sim } 8 . 0$ 之间，近百年的中-强地震活动具有明显的空间不均匀性。区域内的中-强地震活动以走滑断层和正断层型地震为主，近南北向活动裂谷是区域内主要的控震构造，其次是岩石圈尺度的边界走滑断裂 喀喇昆仑断裂（尤其西北段），以及班公湖—怒江缝合带一线的 NE和 NW 向走滑断层[4，6]，尤其对于区域上规模较大或变形更显著的走滑断层最为明显，而且地震活动明显受到了深部构造过程的控制。

# 2    工作内容

# 2.1 调查内容

西藏自治区全区历史地震灾害调查包括相关资料收集、整理、标准化、入库。根据西藏自治区地震灾害风险普查实施方案[7]，该项工作要求全面调查、整理、汇总 1978年以来各县级行政区年度历史地震灾害灾情统计数据，建立 1949 年以来全区重大历史地震灾害事件强度、范围、灾情等要素完整、内容翔实、数据规范的长时间序列重大历史地震灾害时空数据集。

调查内容包括年度历史地震灾害、重大地震灾害事件两部分。年度历史地震灾害调查：1978—2020年各县级行政区逐年历史地震灾害的年度灾害灾情信息，主要包括灾害基本信息、灾害损失信息、救灾工作信息、社会经济信息等；重大地震灾害事件调查：1949—2020 年全区重大地震灾害事件的灾害信息，主要包括重大地震灾害事件强度、范围等基本信息、灾害损失与应对信息、救灾与恢复重建等工作信息。

《国家地震应急预案》将地震灾害分为特别重大、重大、较大、一般共 4级。本次工作中西藏自治区年度地震灾害调查包括一般地震灾害和较大地震灾害调查 2 种，将特别重大、重大地震灾害归于重大地震灾害事件。

# 2.2 年度地震灾害调查

调查范围涵盖自治区、地（市）、县三级行政区域；调查主要内容包括 1978—2020 年发生的年度地震灾害情况、核心灾情指标数据。地震灾害的基本情况数据包括时间、震中、震源深度、震级、受灾人口、死亡人口、直接经济损失、烈度图等。核心灾情指标数据包括当年总人口、当年地区生产总值等基础数据，以及地震灾害报告等。

# 2.3 重大地震灾害事件调查

按照《国家突发公共事件总体应急预案》《国家自然灾害救助应急预案》的有关要求，重大自然灾害指数达到启动国家级Ⅱ级（含）以上应急响应阈值标准的灾害事件，阈值标准按照死亡失踪 100 人及以上判定，倒塌和严重损坏房屋、紧急转移安置人口不作为阈值标准（根据西藏人口分布情况及实际地理环境，调查 $M _ { \mathrm { S } } 6 . 8$ 以上地震）。

调查范围涵盖自治区、地（市）、县三级行政区域（属地管理为主）；调查内容为 1949—2020 年发生的重大历史地震灾害情况，主要包括反映重大历史地震灾害事件总体情况的致灾因子数据、灾区基本情况数据（震级、发震日期、发震时间、震源经度、震源纬度、震源深度、设防烈度、人口密度、灾区 GDP、建筑情况、基础设施情况、宏观震中、震中烈度、受灾范围等），以及人员受灾情况、房屋倒损情况、基础设施损毁情况等灾情数据，包括指标数据、报告数据、专题图数据、照片数据。

# 5    讨论与结论

1978—2020年西藏自治区超过一半的年份发生了地震灾害，时间占比 $6 0 . 4 6 \%$ 。2016—2020 年连续5年发生地震灾害，有愈发频繁的发展趋势。这期间全区 $M _ { \mathrm { S } } 5 . 0$ 以上地震达 600 余次，成灾地震共计 43次，占比约 $7 . 2 \%$ ，该占比主要受地震发生地人口密度及经济发达程度的影响。造成死亡人口历史地震灾害事件 4次，分别为 1980年 11 月 20 日西藏亚东附近 $M _ { \mathrm { S } } 6 . 6$ 地震、1993年 3月 20 日西藏拉孜—昂仁$M _ { \mathrm { S } } 6 . 6$ 地 震 、 2003 年 8 月 18 日 林 芝 波 密 县 $M _ { \mathrm { S } } 5 . 7$ 地震、2008 年 10 月 6 日西藏拉萨市当雄县 $M _ { \mathrm { S } } 6 . 6$ 地震，共造成 17人死亡。根据西藏自治区及下辖地市统计局发布的第七次全国人口普查主要数据，亚东、昂仁、波密、当雄的常驻人口数量在整个西藏自治区并不靠前，说明地震灾害造成人员伤亡事件及伤亡数量随机性比较大，主要是跟西藏自治区地广人稀、居民分散、相距较远有关。

1949—2020年西藏自治区发生的造成重大地震灾害的地震共 5次，1950年（察 隅—墨脱 $M _ { \mathrm { S } } 8 . 6 )$ 、1951 年（当雄 $M _ { \mathrm { S } } 8 . 0 \AA$ ）、1952 年（那曲 $M _ { \mathrm { S } } 7 . 5 )$ 连续 3 年发生重大地震灾害，其余 2 次分别发生在 2008 年阿里地区改则县（ $M _ { \mathrm { S } } 6 . 9 )$ 、2017 年林芝米林县 $M _ { \mathrm { S } } 6 . 9 )$ 。5 次重大地震灾害造成的直接经济损失随着震级降低反而增加（图 6、图 7），从 1950 年（察 隅—墨脱$M _ { \mathrm { S } } 8 . 6 )$ 推断的损失23.1 万元增至2017年（米林 $M _ { \mathrm { S } } 6 . 9$ ）的 19975.55 万元，这种趋势主要受地震发生地当时的经济水平控制。

西藏自治区的地震是典型的大陆地震，空间分布广、震源深度浅、成因类型复杂。1990 年以来发生的 $M _ { \mathrm { W } } { \geqslant } 6 . 5$ 强震受到青藏高原陆陆碰撞-挤出构造体系的控制[6，19]。破坏性地震空间分布在受构造体系控制的基础上，根据西藏自治区的实际情况，主要受地震发生地人口分布、国民经济情况影响。
