# 第一章 总 则

# 1.1 编制目的

为深入贯彻习近平总书记关于新中国气象事业70 周年的重要指示精神，落实中央和省、市关于防灾减灾救灾及应急管理的要求，加强我市气象灾害监测、预报预警、气象防灾减灾等工作，建立健全分工明确、协同高效的气象灾害应急响应机制，提高气象灾害防范、处置能力，最大限度减轻或者避免气象灾害造成的人员伤亡、财产损失，促进“平安深圳”建设和经济社会发展，制定本预案。

# 1.2 编制依据

依照《中华人民共和国突发事件应对法》《中华人民共和国气象法》《中华人民共和国防洪法》《气象灾害防御条例》《中华人民共和国防汛条例》《中华人民共和国抗旱条例》《森林防火条例》《国家突发公共事件总体应急预案》《国家气象灾害应急预案》《气象部门应急预案管理实施办法》《重大气象灾害应急响应启动等级》《广东省突发事件应对条例》《广东省气象灾害防御条例》《广东省气象灾害应急预案》《广东省突发事件预警信息发布办法》《气象灾害防御重点单位气象安全管理办法》《深圳市突发事件总体应急预案》《深圳市突发事件应急预案管理办法（修订版）》《深圳市气象灾害预警信号发布规定》（深圳市人民政府令第 334 号）等法律法规及有关规定，制定本预案。

# 1.3 适用范围

本预案适用于影响深圳市（含深汕特别合作区，下同）和所辖海域的雷雨大风、强季风、雷电、寒冷、高温、大雾、灰霾、冰雹、道路结冰等灾害的防御和应对工作。

因气象因素引发的台风灾害、暴雨灾害、干旱灾害的处置适用于《深圳市防汛预案》《深圳市防台风预案》《深圳市防旱预案》；因气象因素引发水旱灾害、地质灾害、海洋灾害、森林火险等其他灾害，及可能导致安全事故、重大环境事件、工农业生产事件等的处置，适用有关应急预案的规定。

# 1.4 基本原则

以人为本、减少危害。把保障人民群众的生命财产安全作为首要任务和应急处置工作的出发点，最大程度减少灾害损失。

统一领导，分级负责。在市委市政府的统一领导下，气象灾害按照行政区域实施分级管理，各区政府（含大鹏新区管委会、深汕特别合作区管委会）是本行政区域内气象灾害防御工作的责任主体，负责本地区气象灾害的应急处置工作。体现气象灾害工作统一领导、统一指挥、分级分行业负责的原则。

预防为主、科学高效。实行工程性和非工程性措施相结合，提高气象灾害监测预警能力和防御标准；充分利用现代科技手段，做好各项应急准备，提高应急处置能力。

预警先导，部门联动。根据气象灾害监测、预报预警信息，按气象灾害影响程度和范围，及其引发的次生、衍生灾害种类，有关部门按照其职责和预案，启动应急响应机制。

公开透明，协调有序。及时、主动地发布气象灾害信息，加强各区、各部门的信息沟通，做到资源共享，使气象灾害应对工作更加规范有序、运转协调。

# 第二章 组织体系与职责

深圳市气象灾害应急指挥部（以下简称“市气象灾害指挥部”）为全市雷雨大风、强季风、雷电、寒冷、高温、大雾、灰霾、冰雹、道路结冰等 9 类气象灾害的防御和应对指挥机构。在市委市政府和上级气象灾害应急指挥机构指导下开展工作。

# 2.1 指挥机构及其职责

市气象灾害指挥部负责组织、协调和指导全市气象灾害的防御和应急处置工作，负责在预计发生或者已经发生气象灾害时，决定启动和终止实施本预案各级应急响应；指导、协调、督促相关部门做好防灾、减灾和救灾工作；组织制定、公布和实施气象灾害应急预案，开展气象灾害应急演练和宣传教育，组织上报、核定气象灾情信息等工作。

总指挥：由市政府分管气象工作的领导担任。

副总指挥：由市政府协助分管气象工作的副秘书长、市应急管理局主要负责人、市气象局主要负责人担任。

成员单位：各区政府（含大鹏新区管委会、深汕特别合作区管委会）、市应急管理局、市气象局（台）、市消防救援支队、市委宣传部、市发展改革委、市教育局、市工业和信息化局、市公安局、市民政局、市财政局、市人力资源保障局、市规划和自然资源局、市生态环境局、市住房建设局、市交通运输局、市水务局、市商务局、市文化广电旅游体育局、市卫生健康委、市市场监管局、市城管和综合执法局、市口岸办、市建筑工务署、市通信管理局、深圳警备区、深圳海事局、中国电信深圳分公司、中国移动深圳分公司、中国联通深圳分公司、深圳报业集团、深圳广电集团、市水务集团、深圳供电局有限公司、市燃气集团等基础设施营运单位、市地铁集团公司。

市气象灾害指挥部办公室设在市气象局，负责市气象灾害指挥部的日常管理工作，办公室主任由市气象局主要负责人兼任。办公室主要职责：组织气象灾害趋势会商，分析研判气象灾害影响程度和范围，及时向市气象灾害指挥部汇报；根据市气象灾害指挥部决定，启动、变更或终止气象灾害应急响应；建设和完善气象灾害应急处置机制，组织各成员单位开展气象灾害应急演练。

# 2.2 成员单位及其职责

市气象灾害指挥部各成员单位应根据应急响应的级别，按照各自职责，做好气象灾害应急处置工作，启动本单位的应急机制。

（1） 各区政府：负责建立区气象灾害应急指挥部，组织开展本行政区域气象灾害的防御、协调、监督、指导工作；负责组织制定、公布和实施气象灾害应急预案；指挥、协调、督促相关部门做好防灾减灾救灾工作；加大人力、物力、财力保障力度。

（2） 市应急管理局：负责统筹协调气象灾害防灾减灾救灾工作，指导各区政府（含大鹏新区管委会、深汕特别合作区管委会，以下统称各区）和有关单位紧急转移和安置受灾群众；协调有关救援队伍参与救灾行动，协调有关专家指导应急救援工作；统筹指导各区有序开放应急避难场所，协调相关部门调拨救灾款物；负责监督、指导和协调重大气象灾害影响前后安全生产工作；指导组织开展灾后复产；核定、报告和发布灾情信息。

（3） 市气象局（台）:负责组织全市气象灾害监测、预报和预警信息发布等相关工作；承担重大灾害天气跨地区、跨部门的联防监测、预报工作；组织气象灾害风险评价和灾害成因界定工作；建立重大气象灾害应急专家咨询机制，牵头设立专家组，为市、区政府气象灾害预警应急工作提供决策支持等工作。

（4） 市消防救援支队：负责抢救遇险人员，转移和疏散被困群众，协助疏散和营救危险地区的遇险群众。

（5） 市委宣传部：负责组织协调新闻媒体开展防灾减灾宣传教育，指导有关部门（单位）做好气象灾害预警信息发布，引导社会舆论客观正面报道；配合有关部门（单位）做好气象灾害事件新闻发布，及时通报气象灾害事件应急处置工作进展情况。

（6） 市发展改革委：负责安排气象灾害损毁设施修复等相关工程项目，协调落实项目审批和资金计划下达；根据市级救灾物资储备规划、品种目录和标准、年度购置计划，负责市级救灾物资的收储、轮换和日常管理，根据市应急管理局的动用指令按程序组织调出；会同市场监管局加强价格调控监管，开展市场价格巡查，保障重要商品市场供应和价格稳定。

（7） 市教育局：负责协调、指导、监督各地教育部门按照气象灾害预警信号发布情况实施停课机制，保障托幼机构及学校（含学前教育机构，不含技校）学生安全；督促、指导开展危及学校安全的气象灾害隐患排查治理工作；组织、指导学校开展防灾减灾知识宣传、教育、演练等工作，提高师生防灾意识和自救互救能力。

（8） 市工业和信息化局：保障无线电频率资源；负责协调灾区电力应急调用等重要物资供应保障。

（9） 市公安局：负责组织维护灾区社会治安和社会稳定；组织、指导开展治安、交通等方面防灾减灾知识的宣传、教育、演练工作；积极配合做好救灾救援和应急救助工作，组织、指挥、协调公安机关参与抢险救灾，配合当地人民政府组织疏散、撤离受气象灾害威胁的人员；组织警力投入抢险救灾工作；做好灾区交通管制和疏导工作，保证抢险救灾车辆通行。

（10） 市民政局：负责组织、协调福利机构、救助机构对流浪乞讨人员等特殊群体的救助。

（11） 市财政局：负责按照现行财政体制规范，对气象灾害应急处置工作给予相应资金支持。

（12） 市人力资源保障局：完善灾害性天气条件下的劳动关系协调机制，通过宣传和引导，提高用人单位在恶劣天气下保护员工安全的意识；督促全市技工院校根据避险需要适当调整教学秩序，督促全市技工院校执行停课指令。

（13） 市规划和自然资源局：负责海浪、风暴潮等海洋灾害的监测、预报与预警，及时向市气象灾害指挥部提供海洋预报等相关信息；积极协助相关各区做好渔业防风避险以及指导开展生产自救和灾后复产工作，督促指导海上渔船避风、渔排网箱等海上养殖设施防风加固以及渔业作业人员撤离避险。

（14） 市生态环境局：负责气象灾害影响区域的环境监测、处置环境突发事件。牵头协调气象灾害引发的环境事件调查处理及重点区域、流域环境污染防治工作，开展受灾期间环境监测、发布相关环境信息。

（15） 市住房建设局：指导建筑行业安全施工，督促施工单位对在建工程采取安全措施，撤离、转移施工人员；负责组织所辖市政、燃气设施突发事件应急抢险工作以及维护管理和灾后修复工作；负责督促物业公司做好住宅小区的物业管理安全防范工作，协助引导物业服务企业配合当地人民政府、消防救援机构、公安部门等单位开展人员疏散和安全防护工作。

（16） 市交通运输局：负责组织指导协调有关单位和部门做好道路、桥梁、隧道、边坡、客运场站、机场、港口、轨道交通等的气象灾害防御工作，负责交通建设工程、道路交通设施的气象灾害防御工作，及时修复、加固或拆除存在安全隐患或已损坏的设施；组织协调各种交通运力，做好抢险物资和人员输送工作，为抢险救灾工作提供运输保障。

（17） 市水务局：负责水文观测和预警预报，及时提供水文监测信息；组织、指导水务工程设施建设与运行管理单位加强巡查维护，提前预置物资、抢险力量做好水务工程设施抢修准备；加强保障高温和干旱期的居民用水；配合市环境主管部门加强水源水质监测工作，确保用水安全。

（18） 市商务局：负责组织协调有关企业做好生活必需品的市场供应工作。

（19） 市文化广电旅游体育局：负责督促旅行社及时关注气象变化，科学安排旅游线路，引导游客安全出行；督促各 A 级旅游景区、星级酒店及所辖文体场馆做好灾害性天气下安全提示警示和安全运行工作。

（20） 市卫生健康委：负责组织开展灾区伤病员医疗救治工作，向指挥部报告伤病员救治情况；根据需要组织开展卫生防疫工作和伤病员心理危机干预、心理疏导工作，提出保护公众健康的措施建议。

（21） 市市场监管局：负责对食品相关产品、食品（保健食品）生产、流通和餐饮消费环节以及食用农产品流通环节中造成的食品安全事故进行现场控制和违法行为的行政调查处理，并采取必要的应急处置措施。

（22） 市城管和综合执法局：负责督促各区城管部门切实加强户外广告设施和城市照明设施安全监管，制定户外广告设施安全管理应急预案，协调、指导和监督各区城管和综合执法部门根据气象灾害预警级别分级启动应急响应，督促各区落实辖区户外广告安全排查、检查、整改工作，督促城市照明设施管理单位做好城市照明设施的检查和加固工作；负责加强对所管辖区域树木、设施的排查，及时加固、修剪、移除影响安全的树木或设施；负责公园、景区游乐设施发生险情，绿化地冲毁、流沙、滑坡等险情，行道树发生断枝、倒地影响交通等险情的协调处理。

（23） 市口岸办：负责深圳口岸在气象灾害影响期间对港交通、通关安全突发事件的应急处置工作；配合协调各口岸因气象灾害滞留旅客的疏导工作，维护口岸公共秩序。

（24） 市建筑工务署：负责所管辖的施工场地巡查工作，及时消除安全隐患；督促所管辖的在建工地加固或拆除有危险的建筑施工设施，开展应急处置工作，必要时疏散、撤离危险区域人员。

（25） 市通信管理局：负责协调各基础电信运营企业，根据相关规定，配合有关单位发送气象灾害预警预报信息；做好应急通信保障和灾区通信设施的抢修等工作，保障灾害救灾现场等重要通信畅通；及时统计报告全市通信行业受损情况。

（26） 深圳警备区：负责做好抢险救灾的相应准备，必要时迅速参与抢险救灾，协助地方人民政府转移群众。

（27） 深圳海事局：负责督促指导深圳海域商船做好大风、大雾等防御工作；负责海上交通管制工作；牵头组织开展海上险情处置工作。

（28） 中国电信深圳分公司、中国移动深圳分公司、中国联通深圳分公司：做好通信保障，对受损设施和线路进行及时抢修；在市气象局（台）发布高级别预警信息后，通过预警信息快速发布的“绿色通道”，准确、及时地向社会公众发送预警信息。

（29） 深圳报业集团、深圳广电集团：接到气象灾害预警信息15 分钟内，电视台各频道挂出相应的预警信号图标，并按照规定的频率播出相应的预警信息字幕，电台各频率按照规定频率播报相应预警信息，所属相关新媒体平台要及时响应，按要求推送相应预警信息。

（30） 市水务集团、深圳供电局有限公司、市燃气集团等基础设施营运单位：采取措施避免设施遭受气象灾害损坏，调集力量加固、抢修相关设施、设备，保障其正常运行，进而保障水、电、气等正常供应。

（31） 市地铁集团公司：负责做好在建地铁工地、运营线路及上盖物业（管辖范围内）的气象灾害防御工作；及时在地铁媒体上发布气象信息，配合政府相关部门组织做好因气象灾害滞留地铁乘客的疏导工作，维护地铁公共秩序。

各成员单位应根据实际情况，组织做好本部门（单位）的气象灾害防御及相关应急处置工作；其他有关单位应按照职责，配合做好气象灾害防御及相关应急处置工作。

# 2.3 基层气象灾害应急指挥部及职责

按照属地管理原则，各区应建立区气象灾害应急指挥部（以下简称“区气象灾害指挥部”，下同），负责统一组织、协调和指导本行政区域气象灾害的防范和应对工作。区气象灾害指挥部职责：

负责组织、协调和指导辖区内雷雨大风、强季风、雷电、寒冷、高温、大雾、灰霾、冰雹、道路结冰等气象灾害的防御和应急处置工作（台风、暴雨、干旱由防汛防旱防风指挥部负责）；在预计发生或者已经发生气象灾害时，决定启动和终止实施各级应急响应；指挥、协调、督促相关部门做好防灾减灾救灾工作；组织制定、公布和实施气象灾害应急预案，开展气象灾害应急演练和宣传教育，按要求核定和上报气象灾情信息等工作；指导辖区内各街道参照区气象灾害指挥部设置相应完善气象应急管理体系。

区气象灾害指挥部办公室设在区应急管理局，作为气象灾害防灾减灾救灾的综合协调机构。区气象灾害指挥部办公室职责：

负责区气象灾害指挥部日常工作，贯彻落实区气象灾害指挥部工作部署；协调处理气象灾害防御和应急处置工作中的具体问题；组织有关部门、专家会商灾害发生发展趋势；组织收集、调查、评估气象灾害损失和影响；制定和实施气象灾害应急预案；管理气象灾害应急物资和装备仪器；建设和完善气象灾害应急处置机制，组织开展气象灾害应急演练。

# 2.4 应急专家组职责

市、区指挥部应成立应急专家组，或在现有应急专家组内纳入气象及相关专业专家，并健全专家咨询与决策机制，负责对气象灾害发生、发展趋势和处置办法提出意见或建议，为应急处置工作的决策、指挥提供技术支持。

# 第三章 运行机制

# 3.1 预防、监测

# 3.1.1 预防

（1）市气象局应建立健全深圳市气象灾害风险评估机制，开展深圳市气象灾害普查，建立气象灾害数据库，开展气象灾害风险评估与区划，并根据气象灾害分布情况和气象灾害风险评估结果，识别各类气象灾害高风险区域，划定气象灾害风险区域。掌握气象灾害风险隐患底数，借助科技信息化手段，形成“一库”“一图”“一系统”“一平台”（即深圳市气象灾害综合风险普查数据库、风险评估区划图、建设气象灾害综合风险普查及阈值管理系统、陆海一体决策服务平台），为党委政府及各部门有效开展气象灾害防治提供科学决策依据。

（2）各区、各街道和社区应协助做好气象灾害防御知识的宣传和气象灾害应急演练工作。

（3）市有关部门、各区在国家重大建设工程、重大区域性经济开发项目和大型太阳能、风能等气候资源开发利用项目以及城市规划编制中，应统筹考虑气候可行性和气象灾害的风险性，避免、减轻气象灾害的影响。

（4）市有关部门、各区应加强海塘、堤防、避风港、防护林、避风锚地、紧急避难场所等建设，并根据气象灾害情况做好人员转移等准备工作。

（5）市有关部门、各区和相关单位应定期组织开展各种排水设施检查，及时疏通河道和排水管网，加固病险水库，加强对地质灾害易发区和堤防等重要险段的巡查。

（6）气象、建设、交通运输、水务、电力、通信等有关部门要按照谁审批、谁负责、谁监管的原则，切实履行建设工程防雷监管职责，将防雷安全工作纳入本行业安全综合督查、专项检查、执法检查和考核范畴，明确和落实建设工程设计、施工、监理、检测单位以及业主单位等在防雷工程质量安全中的主体责任。规划部门和有关单位应加强各类建（构）筑物、场所和设施安装的雷电防护装置的规划建设，落实防雷有效性检查，从工程措施角度减少雷电灾害的损失。

（7）重点单位应当根据易造成影响的气象灾害种类，建立灾害风险防控机制，加强防风、防涝、防雷等工程设施建设，提高经营场所、设施设备、生产工具、机械装置等的防灾抗灾能力，根据《广东省气象灾害防御重点单位气象安全管理办法》，做好气象灾害防御责任人职责履行、预案编制、预报预警信息接收等防御工作。

# 3.1.2 监测

（1）市气象局（台）组织全市综合气象观测系统的布局、建设和维护，各区、各街道协助气象设施的选址，为气象设施安装、维护等工作提供便利，并配合做好相关气象设施及环境的保护，齐抓共管，实现监测预警信息的共享。

（2）市规划和自然资源局与市气象局（台）负责组织、协调、指导各区建立地质灾害监测预警系统、加强对地质灾害隐患点的监测、掌握地质灾害资料和气象资料，在一定程度上预防突发性地质灾害，从而减轻地质灾害造成的危害。

（3）市气象局（台）与市生态环境局负责统筹协调建立大气成分（灰霾）、城市热岛、温室气体等人居环境气象综合监测网，定期发布相关监测信息。

（4）市规划和自然资源局负责建设海洋气象探测设施，共享观测数据，建立智能化海洋气象救援保障服务系统，提高海洋气象应急保障服务能力。

（5）市气象局（台）与市水务局负责整合水文气象基础设施资源，扩大覆盖范围，优化站网布局，加快应急机动监测能力建设，实现资料共享；加强水文气象精细化预报、预警、评估能力建设，全面提高雨情汛情旱情预报水平；科学开发利用空中云水资源。

# 3.2 预警信息

# 3.2.1 预警信号

气象灾害预警信号是指市气象局（台）根据《深圳市气象灾害预警信号发布规定》，单独或者会同有关部门向社会公众发布的预警信息，是本市防御气象灾害的统一信号，由名称、图标、含义及防御措施组成（详见附件3 《深圳市气象灾害预警信号及防御措施》）。

根据气象灾害的紧急程度、发展态势和可能造成的危害程度，预警信号分为关注级预警、Ⅳ级（一般）、Ⅲ级（较大）、Ⅱ级（重大）和Ⅰ级（特别重大）。

（1）关注级预警

主要包括市气象局（台）发布的：——台风白色预警信号；  
——暴雨黄色预警信号；  
——高温黄色预警信号（预计持续 2 天及以上）；  
——寒冷黄色预警信号（预计持续 2 天及以上）；

——大雾黄色预警信号（预计持续 5 小时及以上）、大雾橙色预警信号；

——雷雨大风黄色预警信号；  
——冰雹橙色预警信号、冰雹红色预警信号；  
——灰霾预警信号；

——强季风蓝色预警信号；——雷电预警信号（特指伴随暴雨、雷雨大风天气的雷电灾害情景）。

（2）Ⅳ级预警

主要包括市气象局（台）发布的：——台风蓝色预警信号；  
——暴雨橙色预警信号；  
——高温橙色预警信号；  
——寒冷橙色预警信号；  
——大雾红色预警信号；  
——雷雨大风橙色预警信号、雷雨大风红色预警信号；  
——强季风黄色预警信号。（3）Ⅲ级预警  
主要包括市气象局（台）发布的：  
——台风黄色预警信号；  
——暴雨红色预警信号；  
——高温红色预警信号；  
——寒冷红色预警信号；  
——强季风橙色预警信号、强季风红色预警信号。

（4）Ⅱ级预警主要包括市气象局（台）发布的：——台风橙色预警信号；——暴雨红色预警信号且 3 小时内降雨量达200 毫米（或 6 小时内降雨量达270毫米、或24 小时内降雨量达 410

毫米）；

——寒冷红色预警信号（寒冷红色预警与道路结冰黄色、橙色、红色任一级别预警信号同时发布时）。

（5）Ⅰ级预警

主要包括市气象局（台）发布的：——台风红色预警信号；——暴雨红色预警信号且 3 小时内降雨量达240 毫米（或 6 小时内降雨量达 320 毫米、或24 小时内降雨量达 460毫米）。

# 3.2.2 分区预警

（1）气象灾害预警信号发布范围包括深圳市管辖区域，并按照以下划分原则进行分区预警：

1）气象灾害预警信号（除地质灾害气象风险预警外）分区预警在陆地上精细化到行政区、街道，一般当连片的三个或以上街道达到发布技术指标时发布，特殊情况可在1-2个街道发布；

2）气象灾害预警信号分区预警在海区精细化至近海海域。

（2）深圳市气象局（台）对雷雨大风、强季风、冰雹、雷电、道路结冰、大雾、灰霾预警信号实行分区预警；高温、寒冷预警在全市范围统一发布，不进行分区预警。

# 3.2.3 预警信息发布

（1）发布制度：遵循“归口管理、统一发布、快速传播”的原则，气象灾害预警信息由市气象局（台）负责制作，并通过市突发事件预警信息发布系统统一发布，其他任何组织和个人不得制作和向社会发布气象灾害预警信息。

（2）发布内容：气象灾害预警信息内容主要包括：气象灾害的种类、预警级别、起始时间、可能影响范围、警示事项、应采取的措施和发布机关等。

（3）传播要求：市有关部门、各区、各街道和社区应通过网站、短信平台、广播、政务微博、政务微信、灾害事故预警系统等渠道准确、及时传播预警信息，实现预警信息全覆盖。

市委宣传部（市政府新闻办）统一协调全市电视台、广播电台、本地网络媒体、移动媒体、户外媒体等社会媒体通过广播电视、门户网站、移动终端等渠道及时向社会公众播发气象灾害预警信息。电信、移动、联通等基础电信运营商应根据应急需求，对手机短信平台进行升级改造，提高预警信息发送效率，在市气象局（台）发布Ⅳ级及以上级别的气象灾害预警信号时，通过预警信息发布的“绿色通道”加频加密向公众免费发送预警信息。公共场所电子显示屏、有线广播、应急广播等传播媒介的所属单位、企业或组织应落实专人负责关注预警信息发布情况，及时接收和传播气象灾害预警信息。

街道、社区、学校、医院、企业、建筑工地等要指定专人负责气象灾害预警信息的接收传递工作，健全工作机制，确保气象灾害预警信息在“最后一公里”有效传递。对老、幼、病、残、孕等特殊人群以及学校等特殊场所和警报盲区应当采取有针对性的公告方式。任何单位不得向公众传播非气象局（台）直接提供的气象灾害预警信息。

# 3.2.4 预警信息调整和解除

市气象局（台）根据气象灾害事态发展，适时调整预警级别并重新发布。气象灾害程度不符合预警条件时，应当立即宣布解除预警信息，终止预警。

# 3.3 应急响应

# 3.3.1 总体要求

（1）根据气象灾害预警信号及事件分级，气象灾害应急响应由低至高依次分为关注级、Ⅳ级（一般）、Ⅲ级（较大）、Ⅱ级（重大）、Ⅰ级（特别重大）响应五个等级。各类气象灾害应急响应标准详见附件 2《深圳市应急响应启动条件一览表》。

（2）气象灾害防御工作按分级管理原则，由各级人民政府和各级气象灾害指挥部组织实施。市有关部门、各区、各街道应当根据气象灾害程度及范围、其引发的次生、衍生灾害程度和范围，以及气象灾害预警信号、响应级别、应急预案和灾害发生情况，依照《中华人民共和国突发事件应对法》和有关法律、法规的规定，按照其职责启动应急响应。

（3）应急响应措施包括密切关注天气变化及灾害发展趋势，加强值班值守，分析评估灾害可能造成的影响和危害，实施预防和控制措施，组织营救、伤员救治、人员转移安置、公共设施的抢修、灾情上报，查明并及时组织力量消除次生、衍生灾害，落实协调应急救援队伍和物资等。

（4）市气象灾害指挥部通过深圳应急一键通 APP 等渠道发布应急响应启动、升级、降级、终止等信息。

# 3.3.2 信息报告和共享

（1）信息报告：气象灾害及其次生、衍生灾害发生后，市有关部门、各区、各街道和社区要按照国家突发事件信息报送的有关规定逐级上报相关信息，并及时续报灾害处置等有关情况。报告的内容主要包括时间、地点、信息来源、灾害性质、影响范围、灾害发展趋势和已经采取的措施等，报告要简明扼要、迅速准确。

发生较大以上气象灾害及其次生、衍生灾害，有关区政府、市有关部门（单位）必须在灾害发生后 30 分钟内通过电话向市委、市政府报告灾害简要情况，并通报灾害可能涉及的区政府及市应急管理局、市气象灾害指挥部办公室等市有关部门（单位）；在灾害发生后 45 分钟内将灾害信息书面报告市委、市政府，通报灾害可能涉及的区政府、市有关部门（单位）。对发生的时间、地点和影响比较敏感的气象灾害及其次生、衍生灾害，可特事特办，不受报送分级限制。

（2）信息共享：市气象局（台）负责发布气象灾害监测预报、预警信息，牵头建立气象灾害及其次生、衍生灾害灾情互通共享机制，与市公安局、市民政局、市规划和自然资源局、市生态环境局、市交通运输局、市水务局、市卫生健康委、市应急管理局、市城管和综合执法局以及铁道、电力、海洋等有关部门实现灾情、险情等信息的及时通报、实时共享。

# 3.3.3 应急响应条件

市气象局（台）发布气象灾害预警信号后，市气象灾害指挥部启动会商机制，及时组织市气象灾害指挥部成员和专家开展会商，综合研判灾害天气的紧急程度、发展态势和可能造成的危害程度。市气象灾害指挥部应根据不同等级预警信号，结合会商结果，启动相应级别的气象灾害应急响应。

发生气象灾害未达到应急响应标准，但可能或者已经造成损失和影响时，根据不同程度的损失和影响，在综合评估基础上启动相应级别应急响应，必要时可提级响应。

启动应急响应后，各有关单位应针对不同气象灾害种类及其影响程度，采取相应的应急响应措施和行动。各类气象灾害的联动部门及应急响应措施详见附件1《深圳市气象灾害分灾种应急预案》。

# 3.3.3.1 关注级应急响应

市气象局（台）发布关注级预警信号时，自行启动关注级应急响应。

关注级应急响应启动后，市有关部门、各区、各街道要密切关注天气变化及灾害发展趋势，按照各自职责，做好有关应急准备工作，有关责任人员要立即上岗到位，组织力量深入分析、评估可能造成的影响和危害，尤其是对本地区、本单位风险隐患的影响情况，有针对性地提出预防和控制措施，落实应急救援队伍和物资，做好升级应急响应的各项准备工作。

# 3.3.3.2 Ⅳ级应急响应（一般）

气象灾害程度达到或可能达到以下情形之一时，市气象灾害指挥部立即启动会商机制，及时对灾害影响及趋势进行综合评估，市气象灾害指挥部办公室主任主持会商。由市气象灾害指挥部决定是否启动Ⅳ级应急响应，并授权市减灾委办公室和市气象灾害指挥部办公室联合签发：

（1）市气象局（台）在全市范围内发布气象灾害Ⅳ级预警信息，或气象灾害影响程度达到市级Ⅳ级应急响应启动标准时；

（2）经对气象灾害的影响及趋势会商研判，确定有必要启动Ⅳ级响应。

# 3.3.3.3 Ⅲ级应急响应（较大）

气象灾害程度达到或可能达到以下情形之一时，市气象灾害指挥部立即启动会商机制，及时对灾害影响及趋势进行综合评估，市气象灾害指挥部副总指挥或办公室主任主持会商。由市气象灾害指挥部决定是否启动Ⅲ级应急响应，并授权市减灾委办公室和市气象灾害指挥部办公室联合签发：

（1）市气象局（台）在全市范围内发布气象灾害Ⅲ级 预警信息，或气象灾害影响程度达到市级Ⅲ级应急响应启动 标准时； （2）经对气象灾害的影响及趋势会商研判，确定有必 要启动Ⅲ级响应。

# 3.3.3.4 Ⅱ级应急响应（重大）

气象灾害程度达到或可能达到以下情形之一时，市气象灾害指挥部立即启动会商机制，及时对灾害影响及趋势进行综合评估，市气象灾害指挥部总指挥或副总指挥主持会商。由市气象灾害指挥部总指挥决定是否启动Ⅱ级应急响应，由市气象灾害指挥部签发：

（1）市气象局（台）发布气象灾害Ⅱ级预警信息；（2）经对气象灾害的影响及趋势会商研判，确定有必要启动Ⅱ级响应。

# 3.3.3.5 Ⅰ级应急响应（特别重大）

气象灾害程度达到或可能达到以下情形之一时，市气象灾害指挥部立即启动会商机制，及时对灾害影响及趋势进行综合评估，市气象灾害指挥部总指挥主持会商。并报请市人民政府决定是否启动I 级应急响应，由市人民政府向各有关单位发布启动相关应急程序的命令，并报告省人民政府：

（1）市气象局（台）发布气象灾害 I 级预警信息；（2）经对气象灾害的影响及趋势会商研判，确定有必要启动I 级响应。

# 3.3.4 联动部门

市、区人民政府要建立健全“政府、部门分级协调，部门、企业分级联动”的应急联动机制。市、区人民政府气象灾害应急指挥部成员单位，特别是交通、民政、通信、供水、供电、供油及教育、农业、医疗卫生等重要行业主管部门要建立部门间应急联动机制，并积极协调、推动相关重点企业之间建立应急联动机制。

发生气象灾害后，相关重点企业按照应急联动机制及时启动应急响应。必要时，由相关行业主管部门按照部门间应急联动机制协调处置，或报请本级人民政府气象灾害应急指挥部协调解决。

# 3.3.5 现场处置

（1）气象灾害现场应急处置由灾害发生地政府或相应应急指挥部统一组织，各部门依职责参与应急处置工作。接到应急响应命令或通知的相关成员单位应立即派工作人员赶赴现场。

（2）必要时，市气象灾害指挥部应派出工作组赶赴灾害现场，视情况组织成立现场指挥部或接过现场指挥权，统一领导、协调、指挥气象灾害现场应急处置。

（3）应急处置工作包括组织营救、伤员救治、疏散撤离和妥善安置受到威胁的人员，及时上报灾情和人员伤亡情况，分配救援任务，协调各级各类救援队伍的行动，查明并及时组织力量消除次生、衍生灾害，组织公共设施的抢修和援助物资的接收与分配。

（4）气象灾害及次生衍生灾害的现场处置在其他市级专项应急预案中有单独规定的，按照有关应急预案执行。

# 3.3.6 信息发布

（1）市、区两级气象灾害应急指挥部按照分级响应原则，负责相关应急处置的信息发布工作。

（2）市、区两级气象灾害应急指挥部应加强信息发布和舆论引导，主动向社会发布气象灾害相关信息和应对工作情况。必要时，组织召开新闻发布会，统一向社会公众发布相关信息。加强舆情收集分析，及时回应社会关切，澄清不实信息，正确引导社会舆论，稳定公众情绪。

（3）气象灾害的信息发布应当及时、准确、客观、全面发布的形式主要包括权威发布、提供新闻稿、组织报道、接受记者采访、举行新闻发布会等。信息发布的内容主要包括气象灾害种类及其次生、衍生灾害的监测和预警，因灾伤亡人员、经济损失、救援情况等。

（4）信息发布要统一发布口径，必要时可报相关地方各级人民政府批准。

# 3.3.7 社会动员

气象灾害事发地的各级人民政府或应急指挥机构可根据气象灾害的性质、危害程度和范围，广泛调动社会力量参与气象灾害处置，紧急情况下可依法征用、调用车辆、物资、人员等。

气象灾害发生后，灾区的各级人民政府或相应应急指挥机构组织各方面力量抢救人员，组织基层单位和人员开展自救、互救；邻近的各区人民政府根据灾情组织和动员社会力量，对灾区提供救助。

鼓励公民、法人和其他组织按照《中华人民共和国公益事业捐赠法》等有关法律法规的规定进行捐赠和援助。审计、监察部门对捐赠资金与物资的使用情况进行审计和监督。

# 3.3.8 响应升级

（1）因气象灾害影响加重，气象灾害预警信号升级，或者气象灾害次生或衍生出其它气象灾害，已经采取的应急措施不足以控制事态发展，需由多个部门（单位）增援参与应急处置的，应及时上报有关部门。

（2）当气象灾害造成的影响程度超出本市控制能力，需要广东省、中国气象局提供援助和支持的，由市委、市政府报请省委、省政府或党中央、国务院协调相关资源和力量参与事件处置。

（3）当上级气象灾害应急救援力量到达现场时，应急处置指挥权相应上移，各成员单位全力配合行动。

# 3.3.9 应急响应降级和终止

气象灾害得到有效处置后，经评估短期内灾害影响不再扩大或已减轻，市气象局（台）发布气象灾害预警降级或解

除信息，市气象灾害指挥部根据综合情况，决定降低应急响应级别或终止响应。关注级应急响应在关注级预警信号解除后自动结束，Ⅰ级应急响应结束指令由市政府批准后发布。

# 3.4 恢复与重建

# 3.4.1 善后处置

受气象灾害影响地区的区政府应当根据本地区遭受损失的情况，制定和实施救助、补偿、抚慰、抚恤、安置等善后工作方案。

# 3.4.2 救灾救济

市应急管理局等部门负责统筹气象灾害社会救助工作，按照政府救济和社会救助相结合的原则，参考《深圳市自然灾害救助应急预案》做好受灾群众的安置工作，会同市有关部门（单位）组织救灾物资和生活必需品的调拨和发放，保障群众基本生活。

红十字会、慈善会等人民团体、社会公益型团体和组织，依据有关法律法规和相关规定，开展互助互济和救灾捐赠活动。

# 3.4.3 保险赔付

巨灾保险制度实施期间，充分发挥巨灾保险的灾害风险转移和损失补偿作用，由市应急管理局协调巨灾保险承保机构，及时开展保险理赔服务工作。各区和相关单位为保险理赔提供支持协助。

# 3.4.4 调查评估

市气象灾害指挥部办公室负责对气象灾害造成的损失及气象灾害的起因、性质、影响等问题进行调查、评估与总结，分析气象灾害应对处置工作经验教训，提出改进措施。由市应急管理局会同有关单位开展灾情核定工作。

# 3.4.5 制定规划

气象灾害处置工作结束后，受到气象灾害影响的区政府应结合调查评估情况，立即组织制定恢复与重建计划，及时恢复社会秩序，修复受损的城市基础设施。

# 第四章 保障措施

# 4.1 人力资源保障

市气象灾害指挥部、各区、各应急救援职能部门应加强人力资源保障，加强各项应急救援能力建设，并通过开展培训、演练等方式提高救援人员的业务素质和技术水平。

各区应采取多种方式配置气象服务专业技术人员，密切关注天气变化和灾害发展趋势，收集并报告灾害性天气影响情况，协助做好辖区气象灾害监测、预报、预警信息的解读等工作。为区气象灾害指挥部在气象灾害的防范和应对工作上提供技术支撑，切实履行辖区气象防灾减灾职责，充分发挥气象防灾减灾第一道防线作用。

各街道应当确定气象信息员或者协理员并报当地气象主管机构备案，为气象信息员或者协理员提供必要工作条件，做好气象灾害预警信息的接收和传播、本行政区域灾害灾情（险情）信息收集和报告，协助做好基层群众防灾避险和应急联络等工作。

应积极发挥共青团、义工联、红十字会等人民团体的作用，鼓励社会团体、企事业单位、基层群众自治组织、志愿者等经过一定的应急救援技能培训后，参与气象灾害的应急救援、善后处置、宣传教育等工作。

# 4.2 经费保障

市、区两级政府应当采取财政措施，保障气象灾害预防和应急处置相关工作经费，并建立资金快速拨付机制。

# 4.3 物资保障

（1）各区、各有关单位应根据本市不同区域气象灾害的种类、频率和特点，按照实物储备与商业储备相结合、生产能力与技术储备相结合、政府采购与政府补贴相结合的方式，充分做好救灾储备整合，实行分级、分类管理，分区域、分部门合理储备一定数量的应急物资，配备必要的应急救援装备。

（2）鼓励和引导社区、企事业单位、社会团体、基层群众自治组织和居民家庭储备基本应急物资和生活必需品。鼓励公民、法人和其他组织为应对气象灾害提供物资捐赠和支持。

# 4.4 人员防护保障

各区、各街道应完善紧急疏散管理办法和程序，明确各级责任人，确保在紧急情况下公众安全、有序转移或疏散到应急避难场所或其他安全地带。

在处置气象灾害过程中，相关单位应充分考虑气象灾害对人员造成危害的可能性和所有危害种类，制定科学合理、切实可行的应急救援方案，配备先进适用、安全可靠的安全防护设备，采取必要的防范措施，确保人员安全。

# 4.5 通信保障

市通信管理局协调各基础电信运营企业、铁塔公司及时恢复遭破坏的通信线路和设施，做好公众网通信保障工作，确保通信畅通。

# 4.6 应急用电保障

担负重要应急机动处置保障的单位，结合气象灾害监测预警信号提前部署，充分利用移动发电装备，为应急处置提供电力保障。

# 4.7 应急避难场所保障

各区、市有关部门（单位）负责本辖区、本行业、本领域的应急避难场所建设、管理和维护工作。灾时由市应急管理部门统一协调使用和管理室内应急避难场所。

# 4.8 科技支撑保障

针对我市的气象灾害风险特点，鼓励和支持有关科研教学单位、学术团体和个人，开展气象灾害预报、预警和应急处置技术与方法研究，做好气象灾害应急技术储备。

# 第五章 监督管理

# 5.1 预案编制

（1）本预案管理遵循统一规划、分类指导、分级负责、动态管理的原则。随着相关法律法规、规范性文件的制定、修改和完善，将定期对本预案进行评估并及时修订。

（2）市、区两级政府及其部门应当针对本辖区内多发易发气象灾害，根据《深圳市突发事件应急预案管理办法》的有关要求，制定本级政府及其部门的应急预案，并根据实际情况变化适时修订和完善。

（3）市、区应急预案一般应当包括总则、应急组织指挥体系与职责、预防与预警机制、应急处置、后期处置、应急保障、监督管理、附则、附件等内容。

（4）附件1 《深圳市气象灾害分灾种应急预案》所涉及的各类气象灾害联动部门，应结合工作职责，制定或完善本单位气象灾害应急预案、抢险应急方案。

（5）有关单位尤其是气象灾害防御重点单位和基层组织应参照本预案，结合工作实际情况，制定完善本单位气象灾害应急预案，或更新完善重点单位综合应急预案中的气象

灾害防御内容。

# 5.2 预案报送备案

（1）市气象灾害指挥部组织编制市气象灾害应急预案，经市人民政府批准后发布，并报省气象灾害指挥部备案。（2）各区气象灾害指挥部组织编制本辖区的气象灾害应急预案，经本级人民政府批准后发布，并报市气象灾害指挥部备案。

（3）街道、社区气象灾害防御组织可根据实际工作需要，与台风、暴雨或自然灾害救助、人员转移疏散等预案共同编制，组织编制本辖区的应急预案，经街道办事处批准后发布，并报区气象灾害指挥部备案。

# 5.3 预案演练

市、区气象灾害指挥部办公室负责组织开展本预案中的气象灾害应急演练。

各区、各有关单位根据市、区两级应急演练计划，定期或不定期开展应急演练。可根据实际情况，结合有关自然灾害专项应急预案一并开展本预案演练。

# 5.4 宣传教育

市、区气象灾害指挥部应当开展气象灾害应急知识宣传教育活动，增强全民防灾减灾意识和预防、避险、自救、互救等能力。

各类学校应当把气象灾害应急知识教育纳入教学计划，定期开展气象灾害应急知识教育，培养学生的安全意识和自救互救能力。

充分利用广播、电视、报纸、互联网以及安全实景模拟教育基地等多种载体，开展气象应急宣传教育。新闻媒体应当无偿开展气象灾害预防和应对、自救互救知识的公益宣传。

# 5.5 责任与奖惩

对在气象灾害应急处置工作中做出突出贡献的先进集体和个人要按照有关规定给予表扬和奖励。对玩忽职守、失职、渎职的有关责任人，依据有关规定严肃追究责任，构成犯罪的，依法追究刑事责任。

# 5.6 预案实施

（1）本预案自发布之日起施行。（2）2018 年深圳市气象局印发的《深圳市气象灾害应急预案》同时废止。

# 5.7 制定与解释

本预案由市气象灾害指挥部负责组织制定，经市政府同意后印发，由市气象灾害指挥部办公室负责解释。

# 附件 1 深圳市气象灾害分灾种应急预案

# 1 .强对流、强季风灾害应急预案

# 1.1 灾害特点

# （1）强对流天气

强对流天气是指发生突然、移动迅速、天气剧烈、破坏力极强的灾害性天气，主要影响有雷雨大风、冰雹等。

雷雨大风突发性强、破坏力大，而且可能伴随冰雹等灾害，造成房屋、临时建筑、棚架、树木和广告牌倒塌伤人，航班延误或取消等。

冰雹往往与雷雨大风同时发生，对农业、房屋有一定破坏，但出现的次数不多，对深圳市社会经济发展影响较小。历史资料显示，近 30 年深圳曾出现过9 次冰雹，最近的一次出现在 2017 年8 月 31 日。

# （2）强季风

强季风指除台风以外的，主要由东北季风和西南季风系统等引起的大风。深圳年平均大风日数有4 天，7-8月出现次数最多，1-4 月出现几率最小。短时强季风天气主要集中在 7-8 月，占全部次数的 $5 0 \%$ 以上。

# 1.2 灾害情景

# （1）影响基础设施

关键区域的电力、通信等设施设备或传输线路、管道损毁造成电力、通信等传输中断。

# （2）影响海陆交通运输

雷雨大风、强季风造成高峰繁忙时段道路、城市轨道等交通受阻，公众上班上学延误；铁路因被风卷入轨道内的异物或滑坡受阻；飞机航班延误或取消，大量乘客滞留。近海海域、江河等水上作业船舶、航行船舶、渔业养殖设施及海上石油平台安全受到严重威胁，甚至引发重大安全事故，造成设施损毁、人员伤亡。

# （3）引发洪涝和地质灾害

雷雨大风带来的强降水可能造成城乡内涝、山洪暴发，引发泥石流、山体滑坡等地质灾害等。

# （4）影响生产安全

企业厂房、围墙倒塌，供电变电站、塔吊、龙门吊及其他大型设备等损毁可能引发安全生产事故及次生、衍生灾害；大型广告牌、电线塔（杆）等被风吹倒，可能造成人员伤亡事故。

# 1.3 防御重点

# （1）做好水、电、气和通讯保障

供水供电供气和通讯等部门要按照职责分工，加强巡查，随时做好快速抢险准备，确保市民生产生活秩序不受影响。

# （2）做好海陆交通运输保障

公安、交通运输部门按各职责分工强化道路的交通管控，加强下沉式隧道、路段的巡查。海事部门加强水上作业、

航行船只监管，科学及时避风。民航要加强航班延误延伸服务。铁路部门强化车辆运行监控，科学及时避险。

# （3）加强生产安全管理

应急管理、工业和信息化、住房建设部门、气象部门按照各自职责适时督促、指导企业开展塔吊、简易厂房、棚架、临时建筑物、易燃易爆、危险化学品、民用爆炸物品等隐患排查工作，及时消除安全隐患，及时开展人员转移，做好安全防护措施。

# （4）做好水上安全作业指导

相关部门指导水上、海上作业船只、人员暂停户外作业，及时避险。

# （5）做好教学秩序调整

教育部门根据预警信号防御指引、提示，指导托幼机构、学校做好因强对流天气导致的延迟上学和放学。

# （6）加强户外场所管理

文化和旅游部门指导、督导 A 级旅游景区及时发出警示信息，适时关闭相关区域，停止营业，组织游客避险。

# 1.4 应急响应

# 1.4.1 强对流天气（雷雨大风、冰雹灾害）应急响应

受强对流天气影响，市气象局（台）发布雷雨大风、冰雹关注级预警信号时，相关区域自动启动关注级响应；市气象局（台）发布Ⅳ级预警信号时，市气象灾害指挥部启动会商机制，对灾害影响及趋势进行综合评估，及时启动Ⅳ级响

应。

启动条件：

（1）关注级响应

——市气象局（台）发布雷雨大风黄色预警信号；  
——市气象局（台）发布冰雹橙色或红色预警信号。

# （2）Ⅳ级响应

——市气象局（台）发布雷雨大风橙色或红色预警信号。

此外，当气象灾害程度加剧，根据灾害造成或可能造成的损失或影响，需要启动更高级别的应急响应时，市气象灾害指挥部应立即组织指挥部成员和专家分析研判，在综合评估基础上启动相关应急响应的程序，向各有关单位发布相关命令。

汛期 1 期间，雷雨大风及任一级别暴雨预警信号同时生效时，相关单位应在市三防指挥部统一领导下开展灾害防御工作。

# 1.4.2 强季风灾害应急响应

市气象局（台）发布强季风关注级预警信号时，相关区域自动启动关注级响应；发布Ⅳ级、Ⅲ级预警信号时，市气象灾害指挥部启动会商机制，对灾害影响及趋势进行综合评估，及时启动Ⅳ级、Ⅲ级响应。

启动条件：

# （1）关注级响应

——市气象局（台）在发布强季风蓝色预警信号，且预计持续两天及以上。

# （2）Ⅳ级响应

——市气象局（台）在发布强季风黄色预警信号。

# （3）Ⅲ级响应

——市气象局（台）在发布强季风橙色或红色预警信号。

此外，当气象灾害程度加剧，根据灾害造成或可能造成的损失或影响，需要启动更高级别的应急响应时，市气象灾害指挥部应立即组织指挥部成员和专家分析研判，在综合评估基础上启动相关应急响应的程序，向各有关单位发布相关命令。

# 2 雷电灾害应急预案

# 2.1 雷电灾害特点

雷电现象是天空中一部份带电的云层内部、云层与云层之间或者云层与大地之间的放电现象。雷电灾害是指云层与大地之间发生的放电并由此而产生对人员、牲畜、建筑物、电子电器设备等的损害，以及引起火灾和爆炸事件，是严重的气象灾害之一。

深圳属雷暴多发区，年平均雷暴日达63 日，以6-9 月份为最多，月均雷暴日都在 10 天以上，年平均雷电密度地理分布特点是：西部多、东部少；内陆多、沿海少；珠江口多、大鹏湾少；山地多、平地少。

# 2.2 雷电灾害情景

雷电灾害引起强大的电流、炙热的高温、强烈的电磁辐射以及猛烈的冲击波等物理效应，能够在瞬间产生巨大的破坏作用，从而造成严重的社会和经济损失。雷电造成的灾害主要是侵入地面的建（构）筑物、设备造成损坏，击中人、畜等造成伤害。雷灾易发生在电力、电信、建筑、石油、化工等行业和空旷地带、居民住宅等场所。

# （1）易燃易爆场所

油库、气库、加油加气站、液化天然气、油 （气）管道站场、阀室等爆炸和火灾危险环境及设施，雷电会引起设备损坏、爆炸或者火灾，造成人员伤亡。

# （2）城市交通

雷电灾害会造成交通受阻，航空、航运、铁路、高速公路、轨道交通等晚点或停运，交通堵塞，乘客滞留。城市交通系统遭遇雷击，可能造成：

轨道交通停止运营；损坏城市交通信号灯，造成城市交通运行系统失灵，造成交通堵塞；城市公交站场所人员伤亡；损坏雷达、导航等电子设备，将使航海、航运停止运行；雷雨天气，航空飞行会有极大的风险，航空停止运营；高速公路收费站遭受雷击，无法进行计费。

# （3）学校

若学校的建（构）筑物防雷设施不合格 ,可能直接遭受雷击，从而引起建（构）筑物损坏或人身伤害事故。防雷装置不按规定要求进行布设,很容易产生雷电波侵入及雷电感应,学校计算机室、语音室、电教室、网络教室、电子阅览室、广播室的设备及程控系统、监控系统等都是雷电波侵入和雷电感应损坏的对象。

# （4）城市电网

雷电已成为城市电网的主要“杀手”之一,雷击会引起线路故障、人员伤亡、设备损坏。大部分的雷电感应和雷电入侵来自于电力传输线，雷击可能造成城市的大面积停电。

# （5）通信基站

深圳的通信基站数量多，密度广，更易遭受雷击。雷击可能造成信号缺失，数据中断，引发一系列连锁的生产和安全事故。

# （6）高层建筑

建筑物中相对高度较高的更容易遭受雷击，深圳的高层建筑更易遭受雷击，造成建筑物损坏或者建筑物内的电子设备损害乃至人身伤害。

# （7）广播电视

雷击会让广播电视设备损坏，造成广播电视信息中断。

# （8）公园、景区、海边和游乐场

雷击会造成在公园、景区、海边、高尔夫球场、山地或者游乐场所的人员受到人身伤害。

# （9）信息系统

雷击使政府信息管理系统、城市安防系统、银行证券电子交易系统、工商税务信息系统等信息系统损坏，影响正常的城市运营，造成工作混乱。

# （10）森林火灾

雷击会引发森林火灾，导致森林火险等级升高。

# （11）户外工地

雷击会使户外工地的工作人员更易受到人身伤害。

# 2.3 防御重点

# （1）日常防雷

日常工作中，企业做好日常安全管理等雷电防御措施，定期完成防雷设施的防雷检测。雷电高发期间，企业加强雷电防御设施隐患排查。

房屋建筑、市政基础设施、公路、水路、铁路、民航、水利、电力、核电、通信等建设工程的主管部门，负责相应领域内建设工程的防雷管理。油库、气库、化学品仓库和烟花爆竹等易燃易爆建设工程和场所，雷电易发区内的矿区、旅游景点或者投入使用的建（构）筑物、设施等需要单独安装雷电防护装置的场所，以及雷电风险高且没有防雷标准规范、需要进行特殊论证的大型项目，其雷电防护装置的设计审核和竣工验收由县级以上地方气象主管机构负责。

# （2）应急响应

# 1）加强监测预报

气象部门加强监测预报，及时发布雷电预警信号及相关防御指引，适时加大预报时段密度；了解雷电影响，进行综合分析和评估工作。

# 2）做好安全生产管理

停止户外易燃、易爆危险作业、水上作业，及时切断室内室外危险电源。有人员活动的露天空旷地带、人员密集场所、高层建筑物、电力电信企业、易燃易爆及危险化学品场所的管理单位应按照预案，做好雷电应对工作，采取必要措施保障易受雷击的设备设施和场所的安全。

# 2.4 雷电灾害应急响应

受伴随暴雨或雷雨大风的雷电气象灾害天气影响，市气象局（台）发布雷电预警信号时，相关区域自动启动关注级应急响应。

当气象灾害程度加剧，根据灾害造成或可能造成的损失或影响，需要启动更高级别的应急响应时，市气象灾害指挥部应立即组织指挥部成员和专家分析研判，在综合评估基础上启动相关应急响应的程序，向各有关单位发布相关命令。

# 2.5 联动部门

各区、市应急管理局、市气象局（台）、市委宣传部、市教育局、市住房建设局、市交通运输局、市文化广电旅游体育局、市城管和综合执法局、市建筑工务署、深圳供电局有限公司、深圳报业集团、深圳广电集团、市地铁集团公司。

# 2.6 雷电灾害应急响应措施

当启动应急响应后，各有关部门和单位要加强值班，密切监视灾情，针对不同气象灾害种类及其影响程度，采取应急响应措施和行动。新闻媒体按要求随时播报气象灾害预警信息及应急处置相关措施。相关应急处置部门和抢险单位随时准备启动抢险应急方案。

# 3 防寒应急预案

# 3.1 寒冷灾害特点

影响深圳的寒潮集中在12 月至翌年 2 月（较多集中于 1月份），平均终日在 2 月初，寒潮活动时间约1 周，约占全年寒潮活动次数的 $5 2 \%$ 。

寒潮通常伴随降温、大风、低温阴雨及“倒春寒”等天气灾害。寒冷低温造成农业冷害、冻害，危害人体健康，给交通物流、能源等领域带来衍生灾害，寒潮天气危害特别严重时，可能在我市的高山、高地道路引发结冰（霜）现象。

# 3.2 寒冷灾害情景

# （1）影响市民健康

寒冷天气可能导致儿童、老人、流浪乞讨人员、困难群众等群体的身体健康因寒冷受到威胁；感冒、咳嗽、发烧、关节炎、中风、心肌梗塞等患者增多，医院就诊量增加；市民使用燃气不当，发生一氧化碳中毒事件。

# （2）影响交通运输

寒冷天气伴随的大风，可能影响航海、航运和航空；如果省内外道路结冰，还会造成交通受阻，铁路列车晚点或停运，大量乘客滞留需要安置，应急救灾物资运输受阻。

# （3）影响水上作业

寒冷天气伴随大风会影响近海海域海上作业、河道水上作业、渔业养殖设施及海上石油平台安全，甚至可能引发重

大安全事故，造成设施损毁、人员伤亡；大风还可能引发海浪灾害。

# （4）影响供电

寒冷天气可能导致供电负荷增高，影响供电稳定；电力设施设备及传输线路因冰冻损坏，电力供应紧张，甚至引发大面积停电事件；寒潮大风可能吹倒电杆、高压铁塔，造成停电。

# （5）影响通信

寒冷天气可能造成通信设施设备及传输线路因冰冻损坏，重要通信枢纽中断。

# （6）影响供水

寒冷天气带来的温度剧烈变化可能导致土壤层出现凸起和塌陷，危及水库、池塘坝体安全；气温降至 $0 \mathrm { ‰}$ 以下时，可能造成供水管网因冰冻损坏。

# （7）影响工地和户外设施

寒潮大风可能造成简易房、围墙，供电变电站、塔吊、龙门吊及其他大型设备等倾倒或损毁，引发安全生产事故及次生、衍生灾害；高空悬挂物、搁置物，户外广告牌等被风吹倒，老化的高层建筑玻璃幕墙、外墙瓷砖和其他建筑材料被风吹落脱，可能造成人员伤亡。

# （8）森林火险等级升高

大风以及伴随的湿度下降，导致森林火险等级升高。

# 3.3 防御重点

# （1）及时开展人员救助

基层街道和社区要提前组织落实困难群众的防寒保暖工作；民政、城管、公安等部门加强对流浪乞讨人员等特殊群体的救助工作，采取防寒保暖救助措施，确保人民群众生命安全。

# （2）加强应急避难场所管理

应急管理部门负责组织落实室内应急避难场所开放，组织室内应急避难场所管理单位做好供电、供水、供气、通信等基础保障，疫情期间加强防疫相关措施。

# （3）严防火灾和一氧化碳中毒

各有关部门和单位加强用电用气安全宣传，组织基层单位和组织、广大市民开展电器、燃气等设备的安全排查，提醒市民安全用电、安全用气，严禁使用直排式燃气热水器，室内取暖注意适当通风。

# （4）做好防灾救灾物资保障

救灾物资储备部门和单位落实防寒衣被、食品等防寒应急物资的采购、征集、储备、调拨、配发等各项准备工作。

# （5）加强公共设备设施巡查维护

市政设施管理部门应当加强市政、公用、交通、电力、通信等公共基础设施的安全保障措施，保障城市生命线的运行安全；加强人员密集场所、公共服务场所的电器、燃气等设备安全巡查维护。

# （6）及早及时发布预警信息

应急、宣传、气象等部门应当依托市预警信息发布平台，加强防寒措施的宣传，及时发布寒冷天气预警信息，通过短信、微信、远程智能预警“大喇叭”、安全管理综合信息系统、各类 LED 显示屏等方式，在社区、居民小组、政府机关、公园、大型商超、学校、酒店、城市候机楼等人流密集场所发布寒冷天气预警信息并循环播放，打通信息发布“最后一公里”。

# （7）做好海上陆上防风工作

当寒冷、强季风预警信号同时发布时，参照防御台风工作指引，各相关部门和单位依职责做好海上陆上防风工作。

# （8）加强森林防灭火工作

各区及市应急管理、林业、城管等部门加强林区、郊野公园等区域巡查，做好森林火灾防范和扑火救援准备。

# （9）做好水、电、气和通讯保障

相关部门和单位加强巡查，随时做好快速抢险准备，确保市民生产生活秩序不受影响。

# （10）统筹做好交通运输保障

加强公路、铁路、民航、航运等各方面的信息汇总，及时发布交通运输相关信息，提醒跨市出行的市民优化、调整出行方式。组织相关单位随时做好大客流滞留的相关准备，妥善做好滞留人员的安置、保暖和分流工作。鼓励市民留在深圳过年。

# 3.4 寒冷灾害应急响应

受寒潮灾害天气影响，市气象局（台）发布关注级预警 信号时，自动启动关注级响应；发布Ⅳ级、Ⅲ级预警信号时， 气象灾害指挥部及时启动会商机制，按照寒冷天气及其影响

程度，启动Ⅳ级、Ⅲ级防冻应急响应；当寒冷程度加剧，灾害造成或可能造成的损失或影响达到高级别应急响应条件时，按相关程序启动Ⅱ级、Ⅰ级应急响应。

启动条件：

# （1）关注级响应

——市气象局（台）发布寒冷黄色预警信号；

——预计因冷空气侵袭，当地气温在 24 小时内急剧下降，降温幅度在 $1 0 \mathrm { { ^ { \circ } C } }$ 以上，或者日平均气温维持在 $1 2 \mathrm { { ^ { \circ } C } }$ 以下。

# （2）Ⅳ级响应

——市气象局（台）发布寒冷橙色预警信号时；——预计因冷空气侵袭，当地最低气温将降到 $5 \mathrm { { ‰} }$ 以下，或者日平均气温维持在 $1 0 \mathrm { { ^ { \circ } C } }$ 以下。

# （3） Ⅲ级响应

——市气象局（台）发布寒冷红色预警信号；

——市气象局（台）发布寒冷橙色预警信号，同时伴有持续性降水；

——预计因冷空气侵袭，当地最低气温将降到 $0 \mathrm { ‰}$ 以下，或者日平均气温维持在 $5 \mathrm { { ‰} }$ 以下。

# （4）Ⅱ级响应

——市气象局（台）发布寒冷红色预警信号，持续时间72 小时以上，预计对我市造成严重影响；

——市气象局（台）发布寒冷红色预警信号，并同时发

布道路结冰黄色、橙色、红色任一级别预警信号；

——市气象局（台）发布寒冷橙色预警信号，并同时伴有持续性降水；

——寒冷天气导致全市高速公路、国道、省道等干线中断 24小时以上，滞留车辆 5000 辆以上；

——寒冷天气导致大范围的电力设施遭受破坏，并对全市电网运行产生严重影响；

——寒冷天气造成部分区域的供水、供气、通信中断，粮油等生活必需品供应紧张，对社会造成较大影响。

# （5）Ⅰ级响应

——寒冷天气导致市内高速公路、国道、省道等干线中断 48小时以上；

——寒冷天气导致大范围的电力设施遭受严重破坏，并对全市电网运行产生极其严重的影响；

——寒冷天气造成全市供水、供气、通信等大范围中断，粮油等生活必需品大范围脱销，并对社会造成极为严重的影响。

各区、市应急管理局、深圳市气象局（台）、市委宣传部、深圳报业集团、深圳广电集团、市交通运输局、市公安局、市民政局、市城管和综合执法局、市卫生健康委。

# 4 高温灾害应急预案

# 4.1 高温灾害特点

深圳年平均高温日数为4.3 天，高温天气均出现在 5-10月，主要集中在 7-9月。历史上记录到的最高气温为 $3 8 . 7 \mathrm { { } ^ { \circ } C }$ 。

# 4.2 高温灾害情景

高温危害人体健康，包括容易引起人体不适、患病甚至中暑；高温给能源、交通、环境等领域带来衍生灾害，如电网超负荷事故，车辆爆胎、车辆自燃等事故；此外，长时间的酷暑天气还会导致供水紧张，引发海洋赤潮的危险。主要灾害情景有：

# （1）影响供电

电网负荷增大，供电紧张，可能引发区域性停电事件。因家庭超负荷用电，导致停电或火灾等事故。

# （2）影响市民健康

户外、露天工作者健康受到威胁，热射病、中暑、心脏病、高血压等患者增加，疟疾和登革热等疾病传播加剧，医院就诊量增加。高温天气易加剧臭氧污染，对人体健康威胁增加。中小学生戏水溺亡事故概率高。

# （3）影响交通运输

高温可能导致汽车驾驶员疲劳驾驶以及汽车爆胎、自燃等交通事故。

# （4）影响生产安全

易燃易爆危险品运输或存放不当可能引发安全生产事故。

# （5）影响农林牧渔业

高温影响农作物产量、水产养殖、树木生长，可能引发森林火灾。

# 4.3 防御重点

# （1）做好水、电、气和通讯保障

供水供电供气和通讯等部门要按照职责分工，加强巡查，随时做好快速抢险准备，确保市民生产生活秩序不受影响。

# （2）做好医疗卫生保障

市卫生健康委牵头负责，建立和完善气象灾害医疗卫生救援预案体系、指挥体系、救援体系，提供应急医疗救治、卫生防疫保障。采取积极应对措施，应对可能出现的高温中暑以及引发的其他疾病。

# （3）做好交通运输保障

公安、交通运输部门做好交通安全管理，提醒车辆减速，防止因高温产生爆胎等事故。

# （4）加强生产安全管理

应急管理、工业和信息化、气象部门按照各自职责适时督促、指导企业开展以易燃易爆、危险化学品、民用爆炸物品为重点的隐患排查工作，及时消除安全隐患，做好高温维护。

# 4.4 高温灾害应急响应

受高温灾害天气影响，市气象局（台）发布关注级预警 信号时，自动启动关注级响应；发布Ⅳ级、Ⅲ级预警信号时， 市气象灾害指挥部及时启动会商机制，对灾害影响及趋势进 行综合评估，启动Ⅳ级、Ⅲ级响应。

启动条件：

# （1）关注级响应

——市气象局（台）发布高温黄色预警信号，且预计高温将持续两天及以上。

# （2）Ⅳ级响应

——市气象局（台）发布橙色预警信号，并预计高温天气仍将持续。

# （3）Ⅲ级响应

——市气象局（台）发布红色预警信号，并预计高温天气仍将持续。

此外，当气象灾害程度加剧，根据灾害造成或可能造成的损失或影响，需要启动更高级别的应急响应时，市气象灾害指挥部应立即组织指挥部成员和专家分析研判，在综合评估基础上启动相关应急响应的程序，向各有关单位发布相关命令。

# 4.5 联动部门

各区、市应急管理局、市气象局（台）、市委宣传部市教育局、市公安局、市民政局、市人力资源保障局、市住房建设局、市交通运输局、市水务局、市文化广电旅游体育局、市卫生健康委、市市场监管局、市城管和综合执法局、市建筑工务署、深圳报业集团、深圳广电集团、深圳供电局有限公司。

# 4.6 高温灾害应急响应措施

# 5 大雾灾害应急预案

# 5.1 大雾灾害特点

深圳的大雾天气集中出现在12 月至次年4 月，最多出现月份为 3 月，最少出现月份为6、7 月。深圳出现连续大雾的次数不多，连续的天数也不长，但近年来大雾出现的频次明显增多。

# 5.2 大雾灾害情景

大雾影响交通航运、供电系统和市民的身体健康。主要灾害情景有：

# （1）影响交通运输

能见度低可能引发道路、水上交通安全事故、飞机航班延误或取消，大量乘客滞留；重要路段因大雾运行受阻，大量车辆、人员、货物无法通行。

# （2）影响供电

大雾天气可能导致供电电网发生“污闪”故障，导致停电、断电。

# （3）影响市民健康

易诱发呼吸系统疾病，甚至导致心血管病、高血压、冠心病、脑溢血等，医院就诊量增加。

# 5.3 防御重点

# （1）做好交通运输保障

公安部门加强对车辆的指挥和疏导，维持道路交通秩序。海事部门及时发布雾航安全信息，督促船舶遵守雾航规

定，加强海上安全监管。民航部门做好运行安全保障、运行计划调整和旅客安抚安置工作。

# （2）做好供电和通讯保障

供水供电供气和通讯等部门要按照职责分工，加强巡查，随时做好快速抢险准备，采取措施尽量避免发生设备污闪故障，及时消除和减轻因设备污闪造成的影响，保障电力供应，确保市民生产生活秩序不受影响。

# （3）做好医疗卫生保障

市卫生健康委牵头负责，建立和完善气象灾害医疗卫生救援预案体系、指挥体系、救援体系，提供应急医疗救治、卫生防疫保障。

# （4）做好宣传教育

针对可能或已经造成的人员、车辆滞留的大雾天气，气象、交通、海事、宣传等部门及时开展公告宣传。

# 5.4 大雾灾害应急响应

受大雾灾害天气影响，市气象局（台）发布关注级预警 信号时，相关区域自动启动关注级响应；市气象局（台）发 布Ⅳ级预警信号时，市气象灾害指挥部启动会商机制，及时 对灾害影响及趋势进行综合评估，启动Ⅳ级应急响应。

启动条件：

# （1）关注级响应

——市气象局（台）在发布大雾黄色预警信号，且预计持续 5 小时及以上；

——市气象局（台）在发布大雾橙色预警信号。

# （2）Ⅳ级响应

——市气象局（台）在发布大雾红色预警信号。

此外，当气象灾害程度加剧，根据灾害造成或可能造成的损失或影响，需要启动更高级别的应急响应时，市气象灾害指挥部应立即组织指挥部成员和专家分析研判，在综合评估基础上启动相关应急响应的程序，向各有关单位发布相关命令。

# 5.5 联动部门

各区、市应急管理局、市气象局（台）、市委宣传部、市教育局、市公安局、市交通运输局、深圳海事局、深圳报业集团、深圳广电集团、深圳供电局有限公司、市地铁集团公司。

# 6 灰霾灾害应急预案

# 6.1 灰霾灾害特点

随着城市建设的迅速发展，灰霾日趋严重。灰霾天气季节差异明显，近10 年数据统计表明：冬季（12月-次年 2 月）灰霾日数最多，占总灰霾日数的 $3 6 \%$ ；其次为秋季（9-11 月），占 $2 9 \%$ ；春季（3-5 月）占 $2 5 \%$ ；夏季（6-8 月）灰霾日数最少，仅占 $1 0 \%$ 。

灰霾直接导致大气能见度下降，影响交通安全；造成供电系统污闪事故增多；还会造成呼吸系统患病率高、佝偻病高发、传染性病菌活性增强；若进一步严重可能产生光化学烟雾。

# 6.2 灰霾灾害情景

# （1）影响交通运输

低能见度可能引发道路交通安全事故；飞机航班延误或取消，大量乘客滞留。

# （2）影响供电

电网发生“污闪”事故，导致停电、断电。

# （3）影响市民健康

直接影响人体健康，严重时出现呼吸困难、视力衰退、手足抽搐等现象，诱发鼻炎、支气管炎、心脑血管、冠心病、心力衰竭等病症，医院就诊量增加。影响在校师生正常学习及往返学校。

# 6.3 防御重点

# （1）做好交通运输保障

公安部门加强对车辆的指挥和疏导，维持道路交通秩

序。民航部门做好运行安全保障、运行计划调整和旅客安抚安置工作。

# （2）做好水、电、气和通讯保障

供水供电供气和通讯等部门要按照职责分工，加强巡查，随时做好快速抢险准备，确保市民生产生活秩序不受影响。

# （3）做好医疗保障

卫生部门采取措施，防范和应对灰霾引起的公共卫生事件。教育、卫生、气象等部门积极宣传灰霾科普知识及防护应对措施。

# （4）加强环保监管

生态环境、气象部门加强监测预报，联合开展空气质量预报、预警会商。环保部门协调重点工业企业落实污染减排措施并加强监管，气象部门根据天气条件适时采取人工影响天气作业。

# （5）指引师生做好健康防护

教育、人力资源保障部门根据灰霾预警信号防御指引、提示，指导师生采取灰霾防御措施，尽量减少学生在室外活动的时间，提醒低能见度下注意交通安全；在有条件的学校安装和启用空气净化器，减少室内大气污染。

# 6.4 灰霾灾害应急响应

受灰霾气象灾害天气影响，市气象局（台）发布灰霾预警信号时，相关区域自动启动关注级应急响应。

当气象灾害程度加剧，根据灾害造成或可能造成的损失或影响，需要启动更高级别的应急响应时，市气象灾害指挥部应立即组织指挥部成员和专家分析研判，在综合评估基础

上启动相关应急响应的程序，向各有关单位发布相关命令。

# 6.5 联动部门

各区、市应急管理局、市气象局（台）、市委宣传部、深圳报业集团、深圳广电集团、市教育局、市公安局、市交通运输局、市生态环境局、市住房建设局、市城管和综合执法局、市建筑工务署。

# 7 其他灾害

# 7.1 台风灾害

我市台风可能出现在4-12月，集中出现在 7-9 月。据历史资料统计，平均每年影响我市的台风 4.2 个，最多年份9个，最少年份1 个。近十年台风有增强的趋势，影响偏早，6 月影响我市的台风增多。台风的影响因登陆地点和台风强度的不同而不同，受大风影响最大的地区是东西部沿海一带，降雨主要集中出现在罗湖、盐田、福田、龙岗西部、龙华区。

台风带来的强风、暴雨和风暴潮，影响海陆空交通、港口码头和建筑工地安全，造成树木和广告牌倒塌伤人和城市内涝等灾害。

我市防风防汛防旱指挥部办公室设在市应急管理局，负责组织、指挥、协调、监督全市三防工作。台风灾害的防御及抢险救灾工作详见《深圳市防台风预案》。

# 7.2 暴雨灾害

我市暴雨主要出现在4-9 月，深圳每年都有暴雨出现，年平均暴雨日数 9.2 天、大暴雨日数2.2 天；暴雨对全年平均雨量的贡献率约为4-5 成，最多的年份为 1690.6 毫米。深圳降水量由东南向西北大致呈递减分布，东部大鹏半岛一带以及盐田区的年降水量普遍在 2100 毫米以上，西部和北部的年雨量普遍在 1900 毫米以下,历史上记录到的最大日降雨量为 498毫米。暴雨对深圳造成的主要灾害为城市内涝和地质灾害。如 3 小时出现100 毫米以上的降水，深圳将出现大范围内涝。

我市防风防汛防旱指挥部办公室设在市应急管理局，负责组织、指挥、协调、监督全市三防工作。暴雨灾害的防御及抢险救灾工作详见《深圳市防汛应急预案》。

# 7.3 干旱灾害

干旱是深圳常见的灾害性天气之一，虽然深圳雨量充沛、雨季时间长，但受季风气候影响，各个季节均有可能出现干旱。干旱造成水库库容骤减，对供水造成影响。干旱期间，灰霾天气增加，空气质量下降，市民呼吸道疾病相应增加。

我市防汛防旱防风指挥部办公室设在市应急管理局，负责组织、指挥、协调、监督全市三防工作。干旱灾害的防御及抢险救灾工作详见《深圳市防旱预案》。

防御措施：

1.进入森林防火防御状态，有关单位加强森林防火宣传教育，普及用火安全指引；

2.加强巡山护林和野外用火的监管工作；

3.森林防火区用火要做好防范措施，勿留火种；

4.充分做好扑火救灾准备工作；

5.政府及相关部门按照预案做好森林火险应对工作。

# （二）森林火险橙色预警信号

图标：

含义：高火险，森林火险气象等级为四级，林内可燃物容易燃烧，森林火灾容易发生，火势蔓延速度快。

防御措施：

1.进入森林防火临战状态，有关单位加强森林防火宣传教育；

2.加大巡山护林和野外用火的监管力度；

3.加强检查，禁止携带火种进山，严格管制野外火源。

# （三）森林火险红色预警信号

图标：

含义：极高火险，森林火险气象等级为五级，林内可燃物极易燃烧，森林火灾极易发生，火势蔓延速度极快。

防御措施：

1.进入紧急防火状态，有关单位加强值班调度，密切注意林火信息动态；

2.加强巡山护林，落实各项防范措施，及时消除森林火灾隐患；

3.严格检查，禁止携带火种进山，严格管制野外火源；

4.政府可以发布命令，禁止一切野外用火，严格管理可能引发森林火灾的生活用火；

5.做好扑火救灾充分准备工作，森林消防队伍要严阵以待；

6.发生森林火灾时要及时、科学、安全扑救，确保人民群众生命财产安全。

# 十一、干旱预警信号

![](images/8ee043e54293246aa3adf5d1bd5ca22cebf607dc11d887592354484bddb858bf.jpg)

含义：连续 3 个月累积雨量比历史同期少（汛期偏少$3 0 \%$ ，非汛期偏少 $5 0 \%$ 以上），且旱情将持续。

防御措施：

1.居民积极节水；

3.适时进行人工增雨作业。

# 十二、地质灾害气象风险预警信号

地质灾害气象风险预警信号分三级，分别以黄色、橙色、红色表示。

# （一）地质灾害气象风险黄色预警信号

含义：24 小时内地质灾害发生的风险较高。

防御措施：

1.居民、车辆尽量避免靠近边坡、挡土墙和沟谷地带，如发现边坡出现异常，立即远离并报警；

2.对于已开展专业监测的隐患点，密切关注监测数据变化，视情况做好单点预警工作；

3.停止地质灾害治理工程户外作业和活动，并采取安全防范措施；

4.相关部门、单位落实值班制度，应对地质灾害隐患开展巡查、排查，妥善安置危险区域人员，发现隐患及时处置；

5.政府及相关部门按照预案做好地质灾害应对工作，相关应急处置部门和抢险单位监视灾情，做好应急抢险救灾工作。

# （二）地质灾害气象风险橙色预警信号

![](images/b823437f28b709dea3d4c782cd74e4358a47db8d7506fc7a6a3a795cd95c3c6e.jpg)

含义：24小时内地质灾害发生的风险高。

防御措施：

1.及时转移危险区域人员；

2.相关部门、单位应加强值班，加大对地质灾害隐患的巡查、排查的频率，尤其加强对削坡建房、重大交通设施、人流密集区等重点区域的巡查排查。

# 十三、雷电预警信号

含义：2 小时内可能受或者已经受雷电影响。

防御措施：

1.居民到安全场所暂避，切勿在树下、电杆下、塔吊下躲避；

2.停止户外易燃、易爆危险作业；

3.有人员活动的露天空旷地带、人员密集场所、高层建筑物、易燃易爆及危险化学品场所的管理单位以及电力电信企业采取必要措施，保障易受雷击的设备设施和场所的安全；

4.政府及相关部门按照预案做好雷电应对工作。

# 附录 2 灾害应急处置流程

# 1. 监测预警

监测预警组负责辖区内灾害隐患点巡查与灾害风险监测，一旦灾害隐患点发生异常或灾害即将来临，立即发出灾害预警，报告领导小组及区（街道）政府（街道办）。

（居）民一旦发现灾情，应立即向社区值班室拨打电话报警告知。

# 2. 应急救援

领导小组负责组织协调灾害救援工作，根据职责分工，灾害救援组、救援队伍负责转移安置受灾人员、救治伤病人员等工作，救灾保障组负责发放救灾款物工作。在能力范围内，对灾害进行应急处置。

# 3. 恢复重建

领导小组负责组织协调灾后安抚与保障工作，根据职责分工，救灾保障组负责受灾人员及家属情绪安抚工作，救灾保障组负责受灾情况核查及灾害调查等工作，救灾保障组、救援队伍负责过渡期生活救助、受灾民宅重建等工作。
