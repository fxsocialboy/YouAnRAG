# 自然灾害灾情统计第 4 部分：统计报表

# 1 范围

本文件为GB/T 24438的第4部分，规定了自然灾害灾情统计报表的分类、编码、格式、内容。  
本文件适用于自然灾害管理部门及其他相关机构对自然灾害灾情的统计调查和信息共享。

# 2 规范性引用文件

下列文件中的内容通过文中的规范性引用而构成本文件必不可少的条款。其中，注日期的引用文件，仅该日期对应的版本适用于本文件；不注日期的引用文件，其最新版本（包括所有的修改单）适用于本文件。

GB/T 24438.1—2009 自然灾害灾情统计 第 1 部分:基本指标GB/T 24438.2—2012 自然灾害灾情统计 第 2 部分:扩展指标

# 3 术语和定义

下列术语和定义适用于本文件。

# 3.1

统计报表 statistical reports

按国家统一规定的表式、统一的指标项目、统一的报送流程，自下而上逐级提供基本统计资料的调查方式方法，是一种具有法律性质的报表。

# 3.2

快报表 case report用于统计单次自然灾害事件造成的损失情况和救灾工作情况的统计报表。

3.3

年报表 annual report用于统计全年（1月1日—12月31日）因自然灾害造成的损失情况和救灾工作情况的统计报表。

3.4冬春救助表 winter-spring relief report用于统计冬令春荒期间受灾人员生活救助情况的统计报表。

3.5一览表 toll report

用于统计个体（人或户）受灾情况和接受救助情况的统计报表。

# B.2 指标填报格式

报表中数量指标均使用阿拉伯数字填写。单位为人、头只、件、个、户、间等整数的数量指标，不保留小数位数；其他无特殊规定的数量指标，小数点后按四舍五入保留2 位小数。
