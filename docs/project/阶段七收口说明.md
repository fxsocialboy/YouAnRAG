## 6. 已知但接受的问题

1. 120 条随机集中 3 条为 `partial`，原因是 DeepSeek Composer 异常后执行模板降级，主链路没有崩溃；
2. V2 平均检索延迟约 2.2 秒、平均端到端约 9 秒，明显高于 Legacy，但完整链路增加了改写、混合召回、精排和生成；
3. DeepSeek 同时承担 Composer 与 Judge，存在同模型偏差，报告已明确披露；
4. AutoDL Legacy Hash 报告因 Windows 绝对路径跨 Linux 映射产生假失败，本地按文件名重映射后 6 个 Legacy 文件 Hash 全部匹配；
5. 人工抽查工作表已冻结 15 条样本，简历仅使用可由自动报告复现的指标。
