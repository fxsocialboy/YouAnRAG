## 3. 正式评测规模

正式评测使用：

```text
35 条自然语言 query
15 条关键词 / 条款 query
共 50 条 query
```

每条 query 对比四种方案：

```text
hybrid
hybrid + rerank
hybrid + MMR
hybrid + rerank + MMR
```

评测指标包括：

```text
doc_recall@10
chunk_recall_exact@10
doc_mrr@10
chunk_mrr_exact@10
rank_shift_vs_hybrid
packed_nonempty_ratio
avg_packed_token_ratio
avg_latency_ms
```

## 4. 核心结果

### 自然语言 query

| Variant | doc_recall@10 | chunk_recall@10 | doc_MRR@10 | chunk_MRR@10 | avg_latency_ms |
|---|---:|---:|---:|---:|---:|
| hybrid | 1.0 | 0.7429 | 0.9238 | 0.5662 | 196.52 |
| hybrid + rerank | 1.0 | 0.6857 | 0.9629 | 0.4398 | 303.68 |
| hybrid + MMR | 1.0 | 0.7429 | 0.9310 | 0.5638 | 321.38 |
| hybrid + rerank + MMR | 1.0 | 0.6857 | 0.9629 | 0.4448 | 399.21 |

结论：自然语言 query 中，rerank 将 `doc_MRR@10` 从 `0.9238` 提升到 `0.9629`，说明相关文档整体更靠前。

### 关键词 / 条款 query

| Variant | doc_recall@10 | chunk_recall@10 | doc_MRR@10 | chunk_MRR@10 | avg_latency_ms |
|---|---:|---:|---:|---:|---:|
| hybrid | 1.0 | 0.9333 | 1.0 | 0.7583 | 154.68 |
| hybrid + rerank | 1.0 | 0.7333 | 0.9222 | 0.3900 | 243.23 |
| hybrid + MMR | 1.0 | 0.9333 | 1.0 | 0.7583 | 324.36 |
| hybrid + rerank + MMR | 1.0 | 0.7333 | 0.9222 | 0.4206 | 387.96 |

结论：关键词/条款 query 中，BM25 + RRF 对精确匹配更稳定，rerank 可能打乱精确条款排序。

## 5. 项目效果评价

当前 RAG 优化效果已经足够支撑简历和面试展示：

1. 从简单 FAISS 检索升级为 `Qdrant dense + BM25 sparse + RRF` 混合召回；
2. 引入 Cross-Encoder rerank，对自然语言 query 的文档级排序有收益；
3. 引入 MMR 多样性控制，并让 ContextPacker 支持 `mmr_score > rerank_score > fusion_score` 三级降级排序；
4. 保留开关与 fallback，保证 reranker/MMR 异常时可退回阶段三 hybrid 链路；
5. 有 50 条人工标注 query、四路消融、延迟统计和自动报告。

因此当前实验规模对个人项目已经足够，不建议继续扩大数据量。继续扩大到 100 条以上会增加标注成本，但对简历收益有限。

## 6. 后续可选优化

阶段四不再继续追加功能。后续如果进入阶段五，建议做：

1. Query Rewrite / Multi-Query / HyDE；
2. query 类型识别：自然语言 query 启用 rerank，关键词/条款 query 保留 hybrid 或降低 rerank 权重；
3. 将最终 evidence 输入到 LLM 生成答案，并补充 citation。

## 7. 面试表述

> 我在原有简单 FAISS 检索基础上重构了一套可评测的 RAG 检索链路：底层用 Qdrant Local 管理 BGE 向量，用 BM25 建关键词倒排索引，通过 RRF 做 dense/sparse 混合召回；在粗排后引入 Cross-Encoder reranker 对 query-passage pair 做精排，并用 MMR 控制上下文证据的多样性。评测上我构造了自然语言和关键词两类 query，做 hybrid、rerank、MMR 的消融实验。结果显示，自然语言 query 的文档级 MRR@10 从 0.9238 提升到 0.9629；而关键词型 query 中 BM25/RRF 更稳定，因此系统保留可配置开关和 fallback，为后续自适应检索策略做准备。
